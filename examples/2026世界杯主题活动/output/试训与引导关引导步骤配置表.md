# 试训关卡与第一关引导关 · 引导步骤配置表

> 定位：把试训关卡、签约后主界面强引导、第一关固定脚本引导拆成可配置步骤。  
> 范围：仅覆盖引导步骤、文案、手势动画、等待操作、保存节点。切片摆位、AI、奖励、关卡胜负仍读取既有关卡/切片配置。

---

## 1. 配置页签概览

| 页签 | 用途 | 维护方 |
|------|------|--------|
| `ActvSoccerGuideStepCfg` | 引导步骤主表，控制触发、聚焦、手势、等待、跳转 | 关卡 / 系统策划 |
| `ActvSoccerGuideTextCfg` | 引导文案表，后续可接语言表 | 文案 / 系统策划 |
| `ActvSoccerGuideGestureCfg` | 手势动画预设表，点击、拖拽、滑动、划线等复用 | UI / 客户端 |
| `ActvSoccerGuideSaveCfg` | 保存节点表，定义每步完成后写入的引导状态 | 程序 / 系统策划 |

---

## 2. `ActvSoccerGuideStepCfg` 字段

| 字段 | 类型 | 说明 | 填表要点 |
|------|------|------|----------|
| `ID` | int | 步骤唯一 ID | 建议按阶段分段：1000 试训、2000 主界面、3000 第一关 |
| `GuideID` | string | 引导组 ID | `trial` / `main_to_level1` / `level1_tutorial` |
| `StepIndex` | int | 组内步骤序号 | 从 1 递增 |
| `Phase` | enum | 所属阶段 | `trial` / `main` / `pre_battle` / `level` / `settlement` |
| `Trigger` | string | 触发条件 | 程序事件或状态条件 |
| `LevelID` | int | 绑定关卡 | 非关卡步骤填 0 |
| `SliceID` | int | 绑定切片实例 | 非切片步骤填 0 |
| `TextID` | int | 文案 ID | 引用 `ActvSoccerGuideTextCfg` |
| `TextStyle` | enum | 文案表现 | `bubble` / `bottom_bar` / `popup` / `toast` |
| `FocusTarget` | string | 高亮对象 | UI 节点名或局内对象 tag |
| `MaskType` | enum | 遮罩类型 | `none` / `full` / `spotlight` / `bottom_safe` |
| `GestureID` | int | 手势预设 | 0 表示无手势 |
| `WaitType` | enum | 等待类型 | `none` / `tap` / `drag` / `swipe` / `release` / `slice_success` / `click_continue` / `auto_delay` |
| `WaitTarget` | string | 等待目标 | UI 节点、操作区域或切片目标 |
| `PassCondition` | string | 通过条件 | 可填事件名或判定表达 |
| `FailAction` | enum | 失败处理 | `none` / `retry_step` / `show_rewind` / `continue_as_failed` |
| `SaveID` | int | 保存节点 | 引用 `ActvSoccerGuideSaveCfg`，0 表示不保存 |
| `NextID` | int | 下一步骤 ID | 0 表示本组结束 |
| `SkipPolicy` | enum | 跳过策略 | `cannot_skip` / `auto_after_delay` / `allow_skip_if_seen` |
| `Remark` | string | 备注 | 仅策划说明 |

|------|------|
| 试训不锁模式 | `trial` 组每个切片允许独立切换操作模式，不写入正式 `mode_lock` |
| 第一关锁模式 | `level1_tutorial` 从第一个非守门切片开始锁定模式，守门切片强制划线 |
| 试训失败 | 不进正式失败和结算，只在当前切片内重试 |
| 第一关失败 | 走正式切片失败和回溯逻辑；玩家放弃后切片可记失败并继续 |
| 第一关重进 | `first_level_tutorial_done=false` 时重复触发引导；中途退出不保存切片进度 |
| 文案接语言表 | `DefaultText` 仅为默认中文，正式接入时应通过 `TextKey` 走语言表 |
| 存档拆分 | 建议使用 `trial_done` 与 `first_level_tutorial_done` 两个字段，不再用单一 `tutorial_done` 表示全部引导 |
