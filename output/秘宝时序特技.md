# 简介

## 设计目的

- **现状问题**
  - 每个部位只有一件可见橙色，效果统一为英雄战力百分比，穿最高品质即最优，没有配装决策也没有成长。
  - 现有的连击、暴击特技与羁绊契约的攻击结算链重叠。
- **本案定位**
  - 契约决定每一次攻击如何结算，秘宝决定一场战斗的四个时序节点——开战、战中、追击、战后——发生什么。
  - 四个部位各承担一个节点，主将的四件秘宝决定部队打法，副将补位。
- **价值边界**
  - 特技的价值落在赢下本场、不回城恢复战力、带进下一场。
  - 不落在补兵与物资上。
- **成长与存量**
  - 特技等级通过合成重复秘宝提升，让重复获得有去处。
  - 存量秘宝全部保留，本案只新增内容。

## 功能简述

- **部位时序职责**：新秘宝按部位固定对应一个时序节点：指环=开战、项链=战中、号角=追击、护符=战后。
- **时序特技**：
  - 首批 12 条特技，每个节点 3 条，分进攻、守御、续战三个方向。
  - 每件新秘宝携带同品质基础战力百分比与一条特技，每场战斗每种特技最多触发一次。
- **影响下一场**：战后节点在真实交战后就地恢复伤兵，或授予部队一个在连战窗口内进入的下一场战斗中生效的效果。
- **按回合计量**：
  - 持续型特技一律表述为"持续 N 回合"（战斗每秒一回合），玩家一眼可懂。
  - 不同时长战局的覆盖率差异是已接受的代价。
- **只认真实交战**：
  - 所有效果只在战斗建立后按回合、兵力阈值或真实交战结算判定。
  - 行军途中发起、取消、改向不产生效果，同一部队短时间内反复与同一目标接战时开战节点受接战冷却限制。
- **每节点一条**：
  - 一支部队每个节点只生效一条特技，主将该部位的特技优先，主将空缺时依次取副将。
  - 同节点其余秘宝仅提供基础战力百分比。
- **产出与投放**：
  - 整件秘宝靠 KVK 赛季产出的征服金币兑换。
  - 碎片靠每日任务、商店与真实交战掉落，可合成任意一件新秘宝，也是特技升级所需重复件的主要来源。
- **特技等级与合成**：消耗同名秘宝提升特技等级，等级只改变特技参数。
- **战报展示**：特技触发结果进入战报，与契约触发展示同级。

# 详细规则

## 全局机制

### 时序节点

- 一场战斗从建立到结算依次经过四个节点，每个节点对应一个部位。
- 节点在一场战斗内各自最多触发一次，交战双方分别判定。
- 所有节点都以战斗真正建立为前提。
- 行军途中发起、取消、改向均不产生效果。

| 节点 | 部位 | 触发时机 | 适用方 |
|------|------|----------|--------|
| 开战 | 指环 | 战斗建立后从第 1 回合起生效，持续配置的回合数 | 双方 |
| 战中 | 项链 | 战斗进行中，我方当前可战兵力占我方开战兵力的比例首次降至该特技阈值以下 | 双方 |
| 追击 | 号角 | 战斗进行中，敌方当前可战兵力占敌方开战兵力的比例首次降至该特技阈值以下 | 双方 |
| 战后 | 护符 | 战斗以胜负结束、结算完成、部队回城处理前，按胜或负分支 | 双方 |

### 回合计量

- **定义**
  - 沿用现有战斗节拍，每秒一回合。
  - 持续型特技从该部队进入本场战斗后的第一个回合起计，第 1～N 回合生效，第 N 回合结束后失效。
  - 免疫期间回合照常计数。
  - 中途加入战斗的部队从其加入起计。
  - 回合计数随战斗结束清零，不跨场。
- **覆盖率**
  - 同一回合数在不同时长的战局中覆盖比例不同，短局全程覆盖、长局只覆盖前段。
  - 这是为玩家可理解性接受的代价，数值按中位战局校准，见「强度校验」。

### 接战冷却

- **记录**
  - 部队每次进入战斗时记录敌方单位与时间。
  - 记录随部队保留至冷却到期，不因回城、驻防或改向清零。
  - 冷却时长由配置表定义。
- **限制**
  - 同一部队与同一敌方单位在冷却内再次进入战斗：开战节点不触发。
  - 战中、追击、战后节点以及已授予的乘胜、坚守照常。
  - 与不同敌方单位进入战斗不受此限制。
- **反馈**
  - 冷却内再次接战的战报在特技段落标注"接战冷却中，开战特技未触发"。

### 每节点一条

- **生效判定**
  - 出征时按节点分别确定生效特技：主将该部位为新秘宝则取主将。
  - 否则依次检查第一副将、第二副将该部位。
  - 未生效的秘宝仍按基础战力百分比计入英雄属性与秘宝战力。
- **部队预览**
  - 秘宝主界面按节点显示当前生效的特技、等级与来源英雄，并标注被覆盖的英雄。
  - 与战斗内实际生效的列表一致。
- **集结与守城**
  - 集结战的开战、战中、追击节点只取集结发起者部队的生效特技。
  - 成员部队的这三个节点不判定。
  - 战后节点按各参与部队各自的胜负与结算分别判定，成员部队的护符正常生效。
  - 守城战所取的部队与契约在同一战斗中所取的部队一致。

### 与其他战斗系统的关系

- 秘宝特技造成的伤害走正常伤害结算，受方按现有比例划分轻重伤，计入战中、追击节点的兵力判定。
  - 但不进入契约结算链：不触发反击、连击、暴击判定，也不被闪避。
- 我方受伤降低、敌方伤害降低、以及英雄技能、契约、科技提供的同类减伤按百分比相加，合计上限由配置表定义。
- 免疫期间不再计算减伤。
- 存量源系列秘宝的连击、暴击词条维持现有触发方式，不占用时序节点。

### 数值框架

- 每条特技的等级提升项按特技等级在配置表定义。
- 阈值等固定项按特技在配置表定义。
- 单条特技对全场伤害的影响按「强度锚点」对标契约同等级。

### 数据兼容总则

| 条目 | 约定 |
|------|------|
| 客户端版本 | 老客户端连新服时，新秘宝按普通秘宝展示（无节点标签、无等级），合成入口不可见；进入秘宝界面提示更新版本。服务端照常结算已装备的时序特技 |

| 幂等 | 装备、卸下、合成的重复请求与重连重放均返回当前最终状态，不重复消耗材料 |

## 时序特技

- **覆盖面**：首批 12 条特技覆盖四个节点，每个节点三条，对应进攻（多打）、守御（少挨）、续战（不回城、连着打）三个方向。
- **结算范围**：
  - 开战、战中、追击三个节点的效果全部在本场战斗内结算。
  - 续战方向在这三个节点表现为战地回战。
- **唯一跨场落点**：战后节点的三条特技全部作用于**下一场战斗**或就地恢复。
- **配装单位**：同方向的四条特技各占一个部位，凑齐即形成一套完整的部队打法。

### 术语与基数

- **回合**：见「回合计量」。
- **开战兵力**：战斗建立时该部队的可战兵力，本场内不变，是战中、追击阈值的分母。
- **阵亡 / 伤兵**：
  - 每次伤害结算时按现有恢复比例把伤害划分为阵亡（永久损失）与伤兵（战斗结束后进入医院）。
  - 本案中"回战"指把伤兵改回可战兵力，回战的士兵不再计为本场伤兵、不进入医院。
- **一次性伤害**：雷霆、斩杀造成的伤害，作为一次独立的伤害结算进入受方流程，不触发受方反击，不进入契约结算链。
- **真实交战**：
  - 本场以一方全灭或撤退形成胜负，且敌方开战兵力不低于我方开战兵力的配置比例（由配置表定义）。
  - 战后节点与碎片掉落都只在真实交战后判定。
- **连战窗口**：
  - 真实交战结束起的一段时间（由配置表定义），部队在此期间进入的下一场战斗享受战后节点授予的效果。
  - 窗口内未进入战斗则效果作废。
- **本方 / 敌方**：
  - 所有特技从携带者部队的视角描述。
  - 双方各自独立持有回合计数、阈值状态。

### 单次伤害结算顺序

- 每一次伤害对受方按下列顺序处理，特技在对应步骤介入。
- 步骤之间不回头重算。

1. **伤害成型**：
   - 攻方普攻或一次性伤害成型，攻方先声与乘胜的加成在此步乘入（若仍在生效回合内）。
   - 契约结算链只作用于普攻。
2. **免疫**：受方护身生效中则全额免疫，本次不再进入后续步骤。
3. **减伤**：受方战阵、坚守（若仍在生效回合内）、受方对攻方施加的压制、以及英雄技能、契约、科技的同类减伤按百分比相加，合计不超过配置上限，一次乘入。
4. **入账**：实际伤害计入受方可战兵力变化。
5. **划分与回战**：
   - 按现有恢复比例划分阵亡与伤兵。
   - 受方救护生效中则本次伤兵 × 回战率立即改回可战兵力。
6. **阈值**：
   - 以受方兵力比例判定受方的战中节点，以受方兵力比例判定攻方的追击节点。
   - 本步触发的一次性伤害作为新的伤害从第 1 步进入对方流程，触发的回战立即改变受方可战兵力。

### 开战节点

- **判定范围**
  - 战斗建立时双方各自生效，不区分进攻方与防守方。
  - 从第 1 回合起持续配置的回合数，回合数走完立即失效，不因兵力变化重新开启。
  - 受「接战冷却」限制：同一部队与同一敌方单位在冷却内再次进入战斗时，开战节点不触发。
- **先声**
  - 定位：开局压制，让战斗前段的交换比向我方倾斜。
  - 效果：
    - 生效回合内我方每次造成伤害时，成型伤害 × (1 + 伤害加成)。
    - 作用于普攻与雷霆、斩杀。
  - 结束：第 N 回合结束。
  - 叠加：
    - 与乘胜、契约额外伤害、克制强化、英雄技能的伤害加成按现有方式合并后一次乘入。
    - 不改变契约的暴击、连击判定。
  - 边界：敌方免疫期间的伤害被免疫，回合照常消耗。
  - 等级示例：加成 15% / 20% / 25% / 30% / 35%，持续 8 / 9 / 10 / 11 / 12 回合。
  - 战报：额外造成的伤害 = Σ(成型伤害 × 加成)。
- **战阵**
  - 定位：开局稳住阵脚，让前段交换比向我方倾斜。
  - 效果：生效回合内我方每次受到伤害时，减伤幅度进入结算顺序第 3 步的百分比相加。
  - 结束：第 N 回合结束。
  - 叠加：
    - 与坚守、压制、其他系统减伤相加并受合计上限约束。
    - 免疫期间回合照常消耗。
  - 等级示例：减伤 10% / 12% / 15% / 18% / 20%，持续 8 / 9 / 10 / 11 / 12 回合。
  - 战报：减免的伤害 = Σ(减伤前伤害 × 本特技占合计减伤的份额)。
- **救护**
  - 定位：前段边打边补，部队在战线上保持规模，不用回城。
  - 效果：
    - 生效回合内我方每次受到伤害并完成阵亡 / 伤兵划分后，本次伤兵 × 回战率立即改回可战兵力，向下取整。
    - 回战部分不计入本场伤兵。
  - 结束：第 N 回合结束。
  - 交互：
    - 回战使兵力比例回升，战中阈值按回升后的比例判定。
    - 与重整、整队、凯旋的基数互不重复（已回战的士兵不再是伤兵）。
  - 边界：单次伤兵不足以回战 1 人时不回战，也不累计。
  - 等级示例：回战率 20% / 25% / 30% / 35% / 40%，持续 8 / 9 / 10 / 11 / 12 回合。
  - 战报：回战的士兵数。

### 战中节点

- **阈值判定**
  - 以我方开战兵力为 100% 基数，在每次受伤结算的第 6 步比较当前可战兵力比例。
  - 三条战中特技阈值由高到低为护身、重整、雷霆，一场战斗中依次触发，各自只触发一次。
  - 同一次结算使兵力跨过多个阈值时，按护身、重整、雷霆的顺序在同一步依次触发。
  - 回战使兵力回升后，已触发的特技不重置。
  - 尚未触发的特技继续按回升后的兵力比例判定。
- **雷霆**
  - 定位：濒危反击，损失越大反击越重。
  - 效果：触发时对敌方造成一次性伤害 = 我方本场累计损失兵力（阵亡 + 伤兵，不含已回战部分）× 伤害比例。
  - 交互：
    - 受敌方战阵、坚守、护身、压制影响。
    - 计入敌方战中阈值判定，可能连锁触发敌方的战中特技。
  - 边界：
    - 触发时我方已被全灭则不结算。
    - 伤害不超过敌方当前剩余兵力。
  - 等级示例：
    - 伤害比例 15% / 19% / 23% / 27% / 30%。
    - 我方阈值固定 30%。
  - 战报：造成的伤害。
- **护身**
  - 定位：濒危时的一口气，给重整、雷霆和援军争取窗口。
  - 效果：触发后从下一回合起我方进入免疫状态，免疫回合内受到的全部伤害（含一次性伤害）全额免疫。
  - 结束：免疫回合数走完。
  - 交互：
    - 免疫期间不计算减伤。
    - 免疫的伤害不计入敌方先声、乘胜的收益，但敌方的回合照常消耗。
    - 免疫期间我方普攻与其他判定照常。
  - 等级示例：
    - 免疫 2 / 2 / 3 / 3 / 4 回合。
    - 我方阈值固定 50%。
  - 战报：免疫的伤害。
- **重整**
  - 定位：濒危时把伤兵拉回战线，用本场损失换续航。
  - 效果：
    - 触发时我方本场累计伤兵 × 回战比例立即改回可战兵力，向下取整。
    - 回战部分不再计为本场伤兵。
  - 交互：回战后兵力比例回升，尚未触发的雷霆继续按新比例判定。
  - 边界：触发时本场伤兵不足 1 则视为已触发、无效果。
  - 等级示例：
    - 回战比例 20% / 25% / 30% / 35% / 40%。
    - 我方阈值固定 40%。
  - 战报：回战的士兵数。

### 追击节点

- **阈值判定**
  - 以敌方开战兵力为 100% 基数，在敌方每次受伤结算的第 6 步比较敌方当前可战兵力比例。
  - 三条追击特技阈值可以相同，同一次结算同时满足时按斩杀、压制、整队顺序触发，各自只触发一次。
  - 敌方回战使其兵力回升后，已触发的追击特技不重置。
  - 尚未触发的继续按回升后的比例判定。
  - 双方都可能进入对方的追击阈值，各自独立判定。
  - 斩杀造成的伤害可能使敌方跨过其战中阈值，连锁触发敌方战中特技。
- **斩杀**
  - 定位：收尾一击，缩短敌方濒危后的挣扎时间。
  - 效果：触发时对敌方造成一次性伤害 = 敌方当前剩余可战兵力 × 伤害比例。
  - 交互：
    - 享受我方先声、乘胜加成（若仍在生效回合内）。
    - 受敌方战阵、坚守、护身、压制影响。
    - 计入敌方战中阈值判定。
  - 边界：敌方处于护身免疫中时伤害被免疫，斩杀视为已触发。
  - 等级示例：
    - 伤害比例 20% / 25% / 30% / 35% / 40%。
    - 敌方阈值固定 30%。
  - 战报：造成的伤害。
- **压制**
  - 定位：防止敌方濒危时的反扑（雷霆、重整后的续战）伤到我方。
  - 效果：触发后敌方造成的全部伤害（普攻、反击、一次性伤害）按降低幅度进入我方结算顺序第 3 步的百分比相加，持续到本场结束。
  - 叠加：
    - 与我方战阵、坚守、其他系统减伤相加并受合计上限约束。
    - 不设回合上限，敌方剩余兵力即天然上限。
  - 等级示例：
    - 降低幅度 20% / 25% / 30% / 35% / 40%。
    - 敌方阈值固定 30%。
  - 战报：减免的伤害 = Σ(减伤前伤害 × 本特技占合计减伤的份额)。
- **整队**
  - 定位：胜局已定时提前整队，带着更完整的部队走出这一场，直接进入下一场。
  - 效果：
    - 触发时我方本场累计伤兵 × 回战比例立即改回可战兵力，向下取整。
    - 回战部分不再计为本场伤兵。
  - 交互：
    - 与重整可以在同一场先后触发，各自按触发时的伤兵基数计算。
    - 回战后兵力比例回升，影响我方尚未触发的战中阈值。
  - 边界：触发时本场伤兵不足 1 则视为已触发、无效果。
  - 等级示例：
    - 回战比例 30% / 35% / 40% / 45% / 50%。
    - 敌方阈值固定 30%。
  - 战报：回战的士兵数。

### 战后节点

- **判定范围**
  - 只在真实交战（见「术语与基数」）后判定。
  - 无胜负结束、或敌方兵力不足比例的战斗不触发。
  - 双方各按自己的胜负分支判定：胜方判定乘胜、凯旋，胜负双方都判定坚守。
  - 同一部队每节点只生效一条。
  - 处理顺序：
    - 凯旋（就地恢复）→ 乘胜 / 坚守（授予下一场效果）。
    - 在本场伤亡结算完成后、伤兵进入医院前处理。
- **授予效果的通用规则**
  - 乘胜、坚守授予的效果挂在部队上，随部队移动。
  - 从本场结束起计连战窗口，窗口内进入的下一场战斗生效，进入战斗即消耗，无论下一场是否真实交战。
  - 窗口内未进入战斗、部队回城驻防、部队解散或被全灭，效果作废。
  - 同一效果再次授予时刷新窗口，不叠加幅度、不延长回合。
  - 授予效果在下一场从第 1 回合起持续配置的回合数。
  - 窗口只约束"何时进入下一场"。
  - 授予效果不受接战冷却限制：它由真实交战产生，本身就付过代价。
  - 集结战中，成员部队的战后节点按各自结算判定，授予效果归各成员部队自身。
- **乘胜**
  - 定位：赢了就接着打，下一场开局更猛。
  - 效果：下一场战斗生效回合内，我方每次造成伤害时成型伤害 × (1 + 伤害加成)。
  - 叠加：与下一场的先声在同一步合并乘入。
  - 等级示例：加成 10% / 13% / 16% / 18% / 20%，下一场前 8 / 9 / 10 / 11 / 12 回合。
  - 战报：
    - 授予时本场战报标注"已获得乘胜"。
    - 下一场战报记录额外造成的伤害。
- **坚守**
  - 定位：刚打完就被第二支部队接上时，不至于被顺手吃掉。
  - 效果：下一场战斗生效回合内，减伤幅度进入我方结算顺序第 3 步的百分比相加。
  - 叠加：与下一场的战阵相加并受合计上限约束。
  - 边界：
    - 本场失败但仍有部队存活（撤退形成胜负）同样授予。
    - 被全灭则无部队可授予。
  - 等级示例：减伤 10% / 12% / 15% / 18% / 20%，下一场前 8 / 9 / 10 / 11 / 12 回合。
  - 战报：
    - 授予时本场战报标注"已获得坚守"。
    - 下一场战报记录减免的伤害。
- **凯旋**
  - 定位：赢了不回城，伤兵就地归队。
  - 效果：
    - 本场累计伤兵（扣除已回战部分）× 恢复比例立即改回可战兵力，向下取整。
    - 剩余伤兵照常进入医院。
  - 交互：
    - 恢复的士兵计入下一场的开战兵力。
    - 与救护、重整、整队的基数互不重复。
  - 边界：本场伤兵不足 1 则视为已触发、无效果。
  - 等级示例：恢复比例 20% / 25% / 30% / 35% / 40%。
  - 战报：恢复的士兵数。

### 强度校验（Lv1，示例）

- 估算口径：现有战斗模型下，每回合各方造成己方剩余兵力 2% 的伤害。
- 持续型特技按 Lv1 持续 8 回合计。
- 下表为三类典型战局中每条特技对本方的影响，最终数值由配置表定义。

| 特技 | 碾压胜（5:1，约 10 回合） | 均势（约 100 回合，双方各损失约 87%） | 惨败（1:5，约 10 回合） |
|------|------|------|------|
| 先声 | 输出 +12% | 输出 +1.2% | 输出 +12% |
| 战阵 | 损失 −8% | 损失 −0.8% | 损失 −8% |
| 救护 | 本场伤兵约 16% 归队 | 本场伤兵约 1.6% 归队 | 本场伤兵约 16% 归队 |
| 雷霆 | 不触发 | 输出 +12% | 输出 +50%（基数极小） |
| 护身 | 不触发 | 损失 −2% | 损失 −20%（多撑 2 回合） |
| 重整 | 不触发 | 伤兵 20% 归队 | 伤兵 20% 归队 |
| 斩杀 | 输出 +6%，提前约半回合结束 | 输出 +7% | 不触发 |
| 压制 | 损失 −3% | 损失 −5% | 不触发 |
| 整队 | 本场伤兵 30% 归队 | 伤兵 30% 归队 | 不触发 |
| 乘胜 | 下一场同先声口径 | 胜方下一场同左 | 不触发 |
| 坚守 | 下一场同战阵口径 | 下一场同左 | 撤退存活时同左 |
| 凯旋 | 剩余伤兵 20% 归队 | 胜方剩余伤兵 20% 归队 | 不触发 |

- **回合覆盖率**（持续 8 回合对近 7 天 PVP 战斗时长分布）：
  - ≤10 回合的战局（占 34%）全程覆盖。
  - 中位 21 回合覆盖 38%。
  - p90 74 回合覆盖 11%。
  - 持续型特技在短局中的价值约为长局的 5～10 倍，这是采用玩家可理解的回合计量所接受的代价。
  - 阈值型（战中、追击）与结算型（战后）不受回合数影响。
- **战局适配**：
  - 碾压局有价值的是开战、追击与战后节点，惨败局有价值的是开战、战中与坚守，均势局以战中、追击为主。
  - 三个方向在三类战局里各有侧重，不存在在所有战局都最优的单一配装。
- **与契约的量级对齐**：
  - 契约 Lv1 的每击期望约为输出 +2.5%～+5% 或承伤 −5%。
  - 持续型特技按中位战局（21 回合）校准到同一量级，短局约为契约的 2 倍、长局约为其 1/4。

### 战报与提示

- **战报**
  - 战报记录本场每条生效特技的名称、等级、生效回合与影响值，交战双方均可见，与契约触发展示并列。
  - 未触发的特技不出现。
  - 战后节点授予的效果在授予场与生效场各记一次。
  - 处于接战冷却内的战斗，战报特技段落标注"接战冷却中，开战特技未触发"。
- **不生效提示**
  - 部队没有任何生效的时序特技时，秘宝主界面部队预览显示「当前部队无时序特技」。
  - 战报不出现特技段落。
  - 部队身上带有未消耗的乘胜、坚守效果时，部队预览与地图部队信息显示剩余连战窗口。

### 候选特技（不进首批）

| 候选 | 节点 | 效果方向 | 暂缓原因 |
|------|------|----------|----------|
| 锁定 | 追击 | 敌方兵力降至阈值后一段时间内不可撤回、不可改向，防止自由行军下的脱战 | 部队级禁止移动为新机制，且现有战斗中撤回规则待战斗程序确认 |
| 破胆 | 开战 | 若干回合内降低敌方概率型战斗机制（契约与英雄被动共用的连击、暴击、闪避、反击）的触发率 | 直接作用于契约体系，需与契约数值一同评估 |

## 产出与投放

- 秘宝的获得分整件与碎片两层。
  - **整件**：靠 KVK 赛季产出的征服金币兑换。
  - **碎片**：靠每日任务、商店与战斗产出，既可合成整件，也是特技升级所需重复件的主要来源。
- 数量、概率与阈值均由配置表定义。
- **两级分工**
  - 征服金币（道具 `100100104`）用于兑换整件新秘宝与源·系列，产出限定在 KVK 赛季内。
  - 秘宝碎片为通用道具，累计达到配置数量即可合成任意一件已解锁的新秘宝，合成结果的特技等级为 Lv1。
  - 金币与碎片不互相兑换。
  - 碎片不可直接提升特技等级，需先合成为整件再按「特技等级与合成」合并。
- **参与型金币产出**
  - 按 KVK 个人积分设阶梯档位，每达成一档发放一次金币。
  - 档位数量、积分阈值与每档发放量由配置表定义。
  - 发放金币的 KVK 成就由一条扩展为多条，覆盖首次参战、累计击杀、累计守城、集结参与等方向。
  - 每条每赛季每人限一次。
  - 个人战场排行与联盟排行的名次奖励保留，作为阶梯之外的增量。
  - 达到本赛季个人上限后，阶梯与成就不再发放，成就条目显示已达本赛季上限。
- **联盟礼物**
  - 名次联盟的礼物改为按成员贡献自动发放，份数随联盟人数计算。
  - 盟主分配保留为额外奖励池，不再是主通路。
  - 同一玩家通过礼物获得的数量并入「赛季上限口径」按赛季累计判定。
  - 已达上限者在自动发放时跳过，份额顺延给下一名成员。
  - 未在有效期内分配完的礼物沿用现有到期自动发放规则。
- **碎片的日常产出**
  - KVK 每日任务：完成指定条目即可获得碎片，条目与数量由配置表定义，按日重置。
  - 破碎大陆金币商店：新增碎片货架，用破碎大陆金币购买，每赛季限购量由配置表定义。
  - 赛季通行证与版本奖励：按档位发放碎片。
- **真实交战掉落**
  - 部队完成一场真实交战（见「术语与基数」）并取胜后，按概率产出碎片。
  - 连续未产出达到配置的保底场次时，下一次真实交战胜利必定产出。
  - 对 NPC 的战斗不产出碎片。
  - 无胜负结束的战斗不计入保底场次。
  - 每日产出上限由配置表定义。
  - 达到上限后不再产出，战报不再显示掉落提示。
  - 产出结果在战报中与特技触发并列展示。
- **商店**
  - 秘宝货架的解锁时点由赛季中期提前至整备阶段结束，具体时点由配置表定义。
  - 每件限购由每赛季一件改为每赛季多件，上限由配置表定义。
  - 金币充足时可连续购买。
  - 货架同时展示碎片合成入口与当前碎片进度。
  - 「前往获取」按当前可用来源跳转。
  - 所有来源均未开放时说明原因与下次开放时间，不显示无效跳转。
- **供给目标**
  - 设计口径：参与 KVK 的玩家、活跃核心、头部三层每赛季可获得的等价件数分层提升，使核心玩家在两个赛季内凑齐一套方向的四件并将主力部位提升至中段等级。
  - 各层的具体等价件数、金币与碎片配比由数值策划在配置表定义。

### 红点规则

- **碎片可合成红点**
  - 触发：碎片数量达到合成任意一件已解锁新秘宝所需数量。
  - 展示位置：
    - 背包秘宝页签的碎片项与商店碎片货架。
    - 向上冒泡至秘宝入口。
  - 消除：完成合成后数量不再满足，或碎片被消耗。
  - 刷新：获得碎片、完成合成、新秘宝解锁时重算。
- **金币可购买红点**
  - 沿用现有商店红点规则：金币足以购买货架上任一未达限购上限的秘宝时显示。

### 数据兼容

- 存量征服金币余额不变，继续可在商店兑换。
- 赛季切换时未使用的碎片与金币保留，不清零。
- 持有上限由配置表定义。
- 阶梯与成就的发放进度按赛季重置。
- 每日碎片任务与掉落上限按服务器日重置。
- 赛季进行中转服或跨服往返的玩家，碎片、金币与本赛季发放进度沿用现有 KVK 数据兼容规则。

## 特技等级与合成

- **等级规则**
  - 每件新秘宝实例有独立的特技等级，初始 Lv1。
  - 等级由该实例累计合并的同名秘宝件数决定，每级所需累计件数由配置表定义，上限由配置表定义。
  - 等级只改变本实例特技的等级提升项。
  - 基础战力百分比、品质与固定项不变。
  - 等级示例：Lv2 / Lv3 / Lv4 / Lv5 分别需累计合并 1 / 3 / 6 / 10 件同名秘宝。
- **合成操作**
  - 目标：
    - 任意一件新秘宝实例。
    - 目标已装备时，其英雄所属部队须处于驻防态。
  - 材料：
    - 与目标同配置的其他实例，且处于未装备状态。
    - 一次可选择多件。
  - 确认时服务器重新校验目标等级、材料归属与装备状态、部队状态。
  - 校验成功：
    - 材料销毁，材料自身的累计合并件数一并计入目标，目标按配置重算等级并立即生效。
    - 已装备的目标同步刷新部队预览与秘宝战力。
  - 目标已满级：合成按钮禁用并提示已达等级上限。
  - 无可用材料：提示无可合成材料，并提供前往获取入口。
  - 材料处于装备中：材料列表中不可选，提示先卸下。
  - 目标所属部队出征中：拒绝合成，提示部队回城驻防后操作。
- **存量秘宝**
  - 不显示等级，不可作为合成目标或材料。

### 红点规则

- **可升级红点**
  - 触发：玩家拥有某件新秘宝实例未满级，且同配置的未装备实例数量达到下一等级所需件数。
  - 展示位置：
    - 背包秘宝页签中对应的秘宝项。
    - 向上冒泡至秘宝页签与英雄详情页的秘宝入口。
  - 消除：完成合成使条件不再满足，或材料被装备、消耗后数量不足。
  - 刷新：获得秘宝、合成完成、装备与卸下变更时重算。
- **闲置可穿红点**
  - 沿用现有规则：对应部位有未装备的可穿秘宝时，槽位与秘宝入口显示红点。

## 装备与部队预览

- **装备规则**
  - 沿用现有装备、卸下与驻防限制。
  - 同部位换新自动卸旧，不消耗、无冷却。
- **选择面板**
  - 按部位过滤时显示每件秘宝的时序节点标签、方向、特技名称与等级。
  - 存量秘宝显示原词条。
- **部队预览**
  - 秘宝主界面在切换编队英雄的同时显示该部队四个节点各自生效的特技，按开战、战中、追击、战后排列，标注生效等级、来源英雄与被覆盖的英雄。

## 边界情况处理

| 场景 | 处理 |
|------|------|
| 主将与副将同部位均为新秘宝 | 按「每节点一条」取主将；副将秘宝仅提供基础战力百分比，预览中标注被覆盖 |
| 主将该部位为存量秘宝、副将为新秘宝 | 存量秘宝词条照常生效，节点特技取副将 |
| 集结成员携带开战、战中、追击特技 | 按「集结与守城」不判定；成员的战后特技按各自结算判定 |
| 部队在一次行军中连续多场战斗 | 每场战斗的节点、回合计数独立判定；开战节点受「接战冷却」限制 |
| 部队反复与同一目标短时接战 | 冷却内的后续战斗不触发开战节点；战中、追击、战后与已授予效果照常，战报标注冷却中 |
| 双方同时进入对方的追击阈值 | 各自独立判定，按各自部队顺序结算 |
| 战斗无胜负结束（援军加入、部队撤回、目标消失） | 战后节点不触发；已触发的开战、战中、追击节点效果保留，回合计数随战斗结束清零；若本场消耗了上一场授予的效果，不退还 |
| 敌方开战兵力不足真实交战比例（打小目标） | 本场其余节点照常，战后节点不触发，不授予效果 |
| 携带授予效果的部队在窗口内进入战斗即被全灭 | 效果已消耗，不退还；无胜负或失败仍可按坚守规则再次授予（有存活部队时） |
| 连战窗口内部队回城驻防 | 授予效果作废，部队预览不再显示 |
| 双方同时携带同一特技 | 各自独立生效，互不抵消 |
| 战斗进行中特技配置热更 | 按「数据兼容总则」以开战时配置结算到结束 |
| 合成时目标或材料状态变化（被装备、被消耗、部队出征） | 服务器校验失败，保留原状态并返回失败原因，客户端刷新列表 |
| 合成请求重复提交或断线重放 | 返回当前最终状态，不重复消耗材料 |
| 玩家已达本赛季金币或碎片上限 | 阶梯、成就与掉落不再发放；联盟礼物自动发放时跳过该玩家，份额顺延给下一名成员 |
| 真实交战条件不满足（打小目标、无胜负结束） | 不产出碎片，也不计入保底场次；战报不显示掉落提示 |
| 碎片足够但对应新秘宝尚未解锁 | 合成列表中该件不可选，说明解锁条件 |
| 老客户端玩家拥有新秘宝 | 按「数据兼容总则」降级展示并提示更新 |
