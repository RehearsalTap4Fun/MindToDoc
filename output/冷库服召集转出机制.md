# 简介

## 设计目的

冷库机制的现实价值是搬迁死号和回收关服，救不了活人：冷库到期强转的对象绝大多数是长期不登录的账号，被强转的活跃玩家留存明显低于未迁移对照，而其中轻付费玩家的留存损失主要来自“落地无盟”。与之相反，通过跨服召集主动转服的玩家几乎不流失，随联盟一起落地的玩家留存增益最大。

因此本功能把冷库服活跃玩家的转出从“无引导自选服、到期强转兜底”改为“在一个召集期内带联盟关系有序迁入推荐的健康服”。机制上只做三件事：冷库服在召集市场双向除名，同时保留其玩家申请召集转出的方向；取消自选服转出，替换为申请推荐联盟、整盟迁入推荐服、个人迁入推荐服三条推荐通道；把整盟迁移从强转时刻前置到召集期内，采用“默认携带活跃成员、可退出”的知情-退出模型。整个冷库流程以一期召集活动为节奏：召集开始前两天预告，召集前三天开放通道并在第三天结束时结算与强转，召集最后两天让已落地的无盟玩家仍能申请推荐联盟。强转仍是兜底，但设计目标是让通道越顺、强转面越小。

同时，真实活跃很低的垂死服提早退出“抢人市场”，避免召集把玩家拉进几个月后就会被强转的服。

## 功能简述

- **召集市场除名**：冷库服自预告开始起，其联盟不可发布召集，其服务器不可被选为召集转入目标；冷库服玩家仍可申请其他服的召集。
- **入口载体**：三条通道以页签形式承载在联盟跨服召集活动页内，冷库服玩家看到申请迁入、联盟迁移、个人迁移三个页签，联盟迁移页签持续展示发起后的目标服与结算倒计时。
- **推荐服池与推荐联盟池**：为冷库服玩家给出同奖励版本、健康、与合服分组映射协同的目标服，以及这些服内可接收的联盟；三条通道全部指向推荐池。
- **通道①申请推荐联盟**：无盟玩家申请推荐联盟，由接收盟审批或免审批直接入盟，落地即有盟；召集期全程开放，强转后仍可继续。
- **通道②整盟迁入推荐服**：盟长在召集 D1–D3 发起，默认携带近期活跃成员，D3 结束时结算并整体迁入推荐服。
- **通道③个人迁入推荐服**：D1–D3 开放的末位出口，落地后由联盟推荐系统补救安置。
- **结算与强转**：召集 D3 结束时关闭通道②③，结算已发起的整盟迁移，其余角色按现行规则强制转移。
- **冷库来源豁免与限流分工**：冷库来源豁免城堡等级门槛与转服冷却并免费；通道①占用单列的冷库来源召集名额，通道②③走迁入总量限流。
- **垂死服召集资格关闭**：真实活跃低于配置阈值的服提早关闭召集发布与接收资格，不与冷库排期绑定。

# 详细规则

## 全局机制

### 冷库流程时间轴

跨服召集活动每 28 天开启一期，每期持续 5 天，文中以 D1 表示召集期首日，日切以服务器日为准。冷库服的预告开始时间与关闭时间按召集期锚定，整个冷库流程在一期召集内完成。

| 冷库日 | 召集日 | 阶段 | 开放内容 |
|--------|--------|------|----------|
| 第 1–2 天 | 召集期前 2 天 | 预告段 | 登录弹窗与邮件预告关闭时间和三条通道；展示推荐服池预览；本服联盟不可发布召集，本服不可被转入；三条通道尚未开放 |
| 第 3–5 天 | D1–D3 | 通道段 | 三条通道全部开放：申请推荐联盟、整盟迁入推荐服、个人迁入推荐服 |
| 第 5 天日切 | D3 结束 | 结算与强转 | 关闭通道②③；结算已发起的整盟迁移；对剩余角色执行强转 |
| 第 6–7 天 | D4–D5 | 补救段 | 仅通道①：已落地的冷库来源无盟玩家可继续申请推荐联盟，审批通过即转入 |
| 第 7 天日切 | 召集期结束 | 结束 | 未处理申请作废；冷库来源身份失效 |

- **冷库来源身份**：玩家在预告开始时所在服为冷库服即获得冷库来源身份；身份随玩家迁移，至当期召集期结束失效。三条通道的豁免、免费与名额口径均以该身份判定。
- **阶段切换以服务器日切为准**；预告开始、通道开放、结算强转、召集结束四个时点均由冷库排期与召集活动配置共同决定。

### 数据兼容总则

| 条目 | 约定 |
|------|------|
| 客户端版本 | 召集活动页新增页签、携带名单确认、冷库来源豁免均由服务器判定；老客户端无法展示新增页签时沿用现有召集与转服入口，服务器仍按本案规则校验目标服，拒绝非推荐目标并返回明确错误 |
| 转服 | 玩家通过任一通道转出后，召集转服时间与个人转服时间照常记录，后续在新服按常规冷却规则生效；冷库来源豁免在身份有效期内生效 |
| 强转后的申请 | 冷库来源玩家在通道①的未处理申请随玩家迁移保留，审批通过时以玩家当前所在服为出发服执行转入 |
| 联盟归属 | 退盟、被踢、退出携带名单立即脱离整盟迁移，联盟维度数据按现有整盟迁移与退盟规则处理 |
| 热更与配置窗口 | 携带窗口、阈值、名额等配置变更于下一召集期生效；进行中的发起、结算与申请不受影响 |
| 幂等 | 申请、发起、取消、确认加入、退出携带均按玩家与联盟当前状态幂等处理，重复请求返回最终状态，不重复计数或扣减名额 |

## 召集市场除名

- **冷库服联盟不可发布召集**
  - 自预告开始起，本服联盟的召集发布、修改、留言入口一律关闭，并提示本服已进入冷库预告。
  - 若冷库排期未与召集期对齐、预告开始时本服联盟仍有生效中的召集，则立即下架，未处理申请按拒绝处理，向申请者发送“目标服务器发生变更”邮件并释放名额。
- **冷库服不可被选为召集转入目标**
  - 他服玩家的召集列表与推荐列表不展示冷库服的联盟。
  - 他服个人迁服与整盟迁服目标列表不展示冷库服。
- **冷库服玩家可申请召集转出**
  - 冷库来源玩家在召集期内可申请推荐联盟池内的联盟，规则见通道①。
- **垂死服同样双向除名**，其玩家的申请、个人迁服与整盟迁服按常规规则进行，见“垂死服召集资格关闭”。

## 冷库转出入口

三条通道全部承载在联盟跨服召集活动页内，以页签区分，不另设独立的转出页面。

- **页签构成**
  - 仍在冷库服的冷库来源玩家，活动页页签为【申请迁入】【联盟迁移】【个人迁移】，分别对应通道①②③，顺序固定；不展示【审批】页签，因冷库服联盟没有召集可审批。
  - 强转落地后的冷库来源玩家在落地服看到常规页签【申请迁入】【审批】，申请迁入页签内按补救段规则展示推荐联盟池。
  - 非冷库来源玩家的页签不变。
- **预告段**
  - 预告开始后，玩家每日首次登录弹出冷库预告，说明关闭时间、三条通道与开放时间，弹窗可直达召集活动页。
  - 三个页签可见但只读：申请迁入展示推荐服池预览，联盟迁移与个人迁移展示通道开放倒计时；任何操作不可用，提示 D1 开放。
  - 自选服转出入口对冷库来源关闭，服务器拒绝冷库来源对非推荐目标的转服请求。
- **通道段（D1–D3）**
  - 三个页签共同展示通道关闭倒计时，即距 D3 结束的剩余时间。
  - 申请迁入页签：展示推荐联盟池，无盟玩家可申请；盟内玩家展示“退盟后可申请”。
  - 联盟迁移页签按身份展示三种状态。
    - 盟长未发起：展示推荐服选择、按携带窗口统计的携带人数预览与发起入口。
    - 已发起：全盟看到目标服、结算倒计时、携带人数与本人携带状态；盟长可取消，名单内成员可退出携带，窗外成员可确认加入；页签显示进行中角标直至结算或取消。
    - 无盟玩家：展示无联盟提示，引导至申请迁入或个人迁移页签。
  - 个人迁移页签：展示推荐服池与迁移入口；盟主展示须先转让盟主或使用联盟迁移的提示。
- **补救段（D4–D5）**
  - 落地服的申请迁入页签对冷库来源无盟玩家展示推荐联盟池与补救提示；有盟玩家展示“已有联盟”。
  - 联盟迁移与个人迁移页签不再展示。

## 推荐服池与推荐联盟池

### 推荐服池

- **准入条件**（同时满足）
  - 与冷库服同奖励版本，含半版本口径一致。
  - 目标服不是冷库服、不在召集资格关闭名单、不处于禁入或维护状态。
  - 目标服昨日 DAU 加当日已迁入人数处于“可直接转入”档；需审批档与禁入档不进入推荐池。
- **排序**：合服分组映射中的锚服 > BI 联盟推荐分的服务器聚合值 > 与玩家同国旗或同语言。展示数量由配置定义。
- **刷新**：DAU 分档随每日数据更新；玩家打开列表时实时按当时限流重新校验，列表内不展示已不满足准入的服。
- **人工覆盖**：运营可配置人工推荐服名单；名单非空时优先展示名单内且满足准入的服。
- **池为空**
  - 同版本内无满足准入的服时，三条通道均展示“暂无可推荐目标，请稍后再试”，并触发运营告警。
  - 运营通过人工推荐服名单指定目标后，通道恢复可用。

### 推荐联盟池

- **来源一（优先）**：当期已发布召集、且冷库来源召集名额大于 0 的联盟，所在服须在推荐服池内。
- **来源二（补充）**：推荐服内有空位的活跃联盟，由联盟推荐系统的活跃联盟名单提供；此类联盟对冷库来源支持免审批直接入盟。
- **排序**：合服映射锚服内的联盟 > BI 联盟推荐分 > 同国旗或同语言；同一联盟只占一个展示位。
- **展示数量**由配置定义；玩家可同时申请的联盟数沿用召集配置。
- **补救段的推荐联盟池**排除玩家当前所在服的联盟，保证通道①始终是跨服转入。

## 通道①：申请加入推荐联盟

- **申请条件**
  - 玩家具有冷库来源身份，且当前召集期开启中（D1–D5）。
  - 玩家当前无盟。
  - 目标联盟在推荐联盟池内，且冷库来源召集名额大于 0。
  - 玩家在目标服的角色数未达上限。
- **冷库来源豁免**：不校验召集城堡等级门槛，不校验召集转服冷却与个人转服冷却。
- **名额**
  - 通道①占用目标联盟的冷库来源召集名额；名额由接收服 DAU 档与接收盟人数档分别配置，取两者与联盟剩余空位的最小值。
  - 名额为 0 时该联盟展示“冷库名额已满”，不可申请；玩家可申请其他推荐联盟或走通道②③。
- **审批**
  - 来源一联盟：由目标联盟 R4 及以上审批，沿用召集审批流程与审批日志。
  - 来源二联盟：免审批，申请即视为通过。
- **通过**
  - 通过后立即以玩家当前所在服为出发服执行转服，落地自动加入目标联盟，登录时展示入盟提示。
  - 通过后在等待时限内未完成转入（如角色数超限），申请作废并释放名额，沿用现有召集处理。
- **强转衔接**
  - D3 结束时仍未审批的申请不作废，随玩家强转保留；D4–D5 审批通过时从落地服转入目标联盟。
  - 强转落地后玩家已通过强转随盟或其他方式入盟的，其未处理申请自动作废并释放名额。
- **拒绝或失效**：向玩家发送召集失败邮件说明原因，玩家在召集期内可继续申请其他推荐联盟。
- **召集期结束**：未处理的申请随活动关闭作废，冷库来源身份同时失效。

## 通道②：整盟迁入推荐服

### 时序

| 阶段 | 召集期日 | 盟长 | 成员 | 系统 |
|------|----------|------|------|------|
| 发起窗口 | D1–D3 | 可随时发起、取消、重新发起，无冷却，无道具消耗 | 名单内成员可退出携带；窗外成员登录确认后加入 | 按携带名单人数一次性预占目标服迁入额度 |
| 结算 | D3 结束 | 不可再取消 | 名单冻结 | 锁定名单，不在名单的成员退盟，执行整盟迁移；未发起的联盟进入强转 |
| 落地 | D4–D5 | 无系统动作 | 落地后正常运行 | 无 |

### 发起

- **发起校验**
  - 发起人为盟长，联盟当前不处于迁移中，本服处于通道段。
  - 目标服在推荐服池内且与本服同奖励版本。
  - 目标服按当前携带名单人数一次性预占迁入额度；额度不足时发起不成立，提示更换推荐服。
- **发起成功**
  - 全盟收到迁移预告；联盟迁移页签转为进行中状态，持续展示目标服、结算倒计时、携带人数与每位成员的携带状态，直至结算或取消。
  - 目标服预占额度立即生效，不再受同日其他迁入影响。
- **取消**
  - 结算前盟长可随时取消，取消释放预占额度，成员携带状态清零，可在通道段内重新发起。
  - 取消不产生冷却。

### 携带名单

- **默认携带**：发起时近 7 天内有登录的成员，窗口天数由配置定义；不作农场判定。
- **默认不带**：窗口外成员。
  - 其在结算前登录并确认加入时进入名单，同时校验目标服额度；额度不足则提示无法加入，并引导走通道①③。
- **退出携带**
  - 名单内成员在结算前可退出携带，退出即退盟，转为无盟状态，可在通道段内走通道①③。
  - 成员在结算前退盟或被踢出，自动脱离名单。
- **额度同步**：名单人数变化时同步更新预占人数；确认加入需重新校验额度，退出只释放额度。
- **角色数校验**：成员在目标服的角色数达到上限时不能随盟迁移，在结算时自动退盟并邮件说明。

### 结算与执行

- **结算顺序**：D3 结束时先处理所有已发起的整盟迁移，再对本服剩余角色执行强转，保证名单内成员不会被强转拆散。
- **锁定**
  - 结算时冻结名单，此后不可取消、不可退出、不可加入。
  - 不在名单的成员自动退盟并收到邮件，说明联盟已迁往哪个服；这些成员作为剩余角色进入强转，落地后可在 D4–D5 走通道①。
- **执行**
  - 按现有整盟迁移流程执行；迁移中的联盟拒绝新成员加入，迁移完成后原服联盟数据按现有规则清理。
  - 目标服暂时不可用时保留名单并按现有间隔重试，重试期间名单内成员不参与强转；至 D5 结束仍失败，则联盟按强转规则整盟迁往平台匹配服，并邮件通知全盟。
- **落地**：联盟与成员落地后按整盟迁移现有规则恢复联盟数据，成员登录展示落地提示。

### 未发起的联盟

- D3 结束时仍未发起整盟迁移的联盟，按强转规则整盟迁往平台匹配服，携带全部成员。

## 通道③：个人迁入推荐服

- **条件**
  - 玩家具有冷库来源身份，本服处于通道段（D1–D3）。
  - 玩家不是盟主；盟主须先转让盟主或走通道②。
  - 目标服在推荐服池内，玩家在目标服角色数未达上限。
- **冷库来源豁免**：不校验个人转服城堡等级门槛，不校验转服冷却，不消耗转服道具。
- **限流**：不占召集名额，按目标服迁入总量限流正常计数。
- **执行**：沿用个人迁服流程；有盟玩家迁出时自动退盟并脱离携带名单。
- **落地安置**：落地后不入盟，触发联盟推荐系统对无盟玩家的推荐弹窗或直接入盟机制进行二次安置；落地玩家在 D4–D5 仍可走通道①。
- **关闭**：D3 结束时通道关闭，进行中的迁服照常完成。

## 冷库来源豁免与限流分工

| 通道 | 开放窗口 | 召集名额 | 迁入总量限流 | 豁免项 | 费用 |
|------|----------|----------|--------------|--------|------|
| ①申请推荐联盟 | D1–D5 | 占用冷库来源单列名额 | 随召集流程 | 城堡等级门槛、召集转服冷却、个人转服冷却 | 免费 |
| ②整盟迁入推荐服 | D1–D3 | 不占用 | 按携带名单人数一次性预占 | 城堡等级门槛、转服冷却 | 免费 |
| ③个人迁入推荐服 | D1–D3 | 不占用 | 正常计数 | 城堡等级门槛、转服冷却 | 免费 |

- 豁免与免费只对具有冷库来源身份的玩家生效；垂死服（未进入冷库）玩家按常规召集与迁服规则处理。

## 垂死服召集资格关闭

- **判定**
  - BI 每日产出各服真实活跃人数，剔除农场号与测试号。
  - 真实活跃低于配置阈值（暂定 30）的服进入召集资格关闭名单。
- **效果**
  - 名单内服的联盟不可发布召集，其服务器不可被选为召集转入目标。
  - 名单内服的玩家仍可申请他服召集，可按常规规则个人或整盟迁出。
- **生效与恢复**
  - 名单变化于下一召集期开始时生效，保证一期内规则稳定；当期已发布的召集不下架。
  - 脱离名单的服于下一召集期恢复资格。
  - BI 名单未更新时沿用上一日名单。
- **与冷库关系**：资格关闭独立于冷库排期；服进入冷库预告后按冷库规则处理。

## 结算与强转

- **时点**：召集 D3 结束时执行；先结算已发起的整盟迁移，再对本服剩余角色执行强转。
- **强转规则不变**：剩余角色由平台匹配目标服强制迁移；有盟玩家随联盟整体迁移，无盟玩家个人迁移，落地登录收到强转说明邮件。
- **强转后的补救**：被强转的无盟玩家在 D4–D5 保留冷库来源身份，可通过通道①申请推荐联盟；其在 D3 前提交的申请继续有效。

## 红点规则

| 红点 | 触发 | 消除 | 位置 |
|------|------|------|------|
| 召集活动入口 | 预告开始首次登录；D1 通道开放时重新触发 | 打开召集活动页 | 活动入口 |
| 可发起整盟迁移 | 盟长所在联盟处于通道段且未发起 | 发起后或结算后 | 联盟迁移页签 |
| 确认加入携带名单 | 本盟已发起且自己是窗外成员 | 确认加入、结算或迁移取消 | 联盟迁移页签 |
| 补救段申请推荐联盟 | D4–D5 已落地的冷库来源无盟玩家 | 打开申请迁入页签 | 落地服召集活动入口 |

红点均由服务器按状态计算，页签红点向活动入口冒泡，沿用召集入口的现有冒泡规则。

## 边界情况处理

| 场景 | 处理 |
|------|------|
| 冷库排期未与召集期对齐，预告开始时本盟仍有生效中的召集 | 立即下架，未处理申请作拒绝并邮件通知，释放名额 |
| 预告开始时玩家已有通过待转入的他服召集申请 | 照常完成转服 |
| 预告开始时联盟正处于旧流程整盟迁移中 | 照常完成；目标服不是冷库服 |
| 预告段内尝试任一通道操作 | 拒绝并提示 D1 开放 |
| 申请后目标联盟所在服进入冷库、资格关闭或禁入 | 申请失效并邮件说明，名额释放 |
| 通道①申请在 D3 结束时未审批 | 申请保留，玩家随强转迁移；D4–D5 审批通过从落地服转入 |
| 强转落地后玩家已随盟或已入盟 | 其未处理申请自动作废并释放名额 |
| 盟内玩家想走通道①或③ | 退盟后即脱离携带名单并可申请；系统不做额外互斥规则 |
| 结算后成员想退出 | 不允许，随盟迁移 |
| 迁移中转让盟主 | 沿用整盟迁移中禁止转让 |
| 携带名单成员被踢或退盟 | 自动脱离名单，预占人数同步减少 |
| 发起后目标服当日 DAU 档变化 | 已预占额度不受影响；新发起按最新档判定 |
| 结算时目标服不可用 | 保留名单按间隔重试，名单内成员暂不强转；至 D5 结束仍失败，联盟按强转规则整盟迁往平台匹配服 |
| D3 结束时联盟未发起整盟迁移 | 按强转规则整盟迁往平台匹配服 |
| 同一通道段内重复发起 | 取消后可重新发起；未取消时重复发起返回当前状态 |
| 版本切换前后保护窗口内发起或申请 | 沿用迁服引擎的版本切换保护，提示稍后再试 |
| 断线重连、重复点击 | 申请、发起、取消、确认、退出均幂等，返回最终状态 |
| 服务器维护跨过 D3 日切 | 恢复后立即执行结算与强转，不顺延到下一期 |
| 热更调整携带窗口或阈值 | 下一召集期生效，进行中名单不重算 |
| 推荐服池与人工名单均为空 | 通道展示不可用，触发运营告警，不回退到自选服 |
| 通道③迁服在 D3 日切时进行中 | 照常完成，不参与强转 |

# BI 效果指标

| 指标 | 基线 | 方向 |
|------|------|------|
| 冷库活跃玩家中经随盟或入盟落地的比例 | 接近 0 | 核心目标，越高越好 |
| 强转中的活跃玩家占比 | 转后 28 日登录口径约一成 | 下降趋零 |
| 被强转活跃玩家第 4 周留存与未迁移对照的差距 | 付费档低 6 至 11 个百分点 | 随强转面缩小收敛 |
| 召集拉入后来关闭服的人次 | 每年约 2300 人 | 资格关闭生效后趋零 |
| 整盟迁移使用量 | 每年约 11 人次 | 成为冷库联盟主通道 |
| 补救段通道①申请与通过率 | 无 | 观察强转后无盟玩家的二次安置效果 |

- **通道区分**：转出记录须区分通道①②③、强转、补救段通道①，并记录目标服是否为合服映射锚服。
- **失败原因**：至少区分名额已满、额度不足、目标不可用、角色数上限、召集期外、玩家状态变化。
- **回归观察**：观察通道③与强转落地玩家的二次安置成功率与留存，以及结算退盟成员的后续去向。
