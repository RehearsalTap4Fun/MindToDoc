# K1新服大地图重构功能策划案 · 配置表结构（数值策划填表）

> **定位**：本文只描述数值、地图、活动策划在 Excel 中需要维护的配置结构。  
> **规则依据**：主策划案 [K1新服大地图重构功能策划案.md](K1新服大地图重构功能策划案.md)。  
> **列级 SSOT**：如项目已有正式 Excel，以正式表头为准；本文用于对齐应有哪些配置页签与字段含义。

# 文档边界

## 本文档包含

- 新服大地图基础参数、分区、方格、堡垒、龙巢、圣坛、王座入口、迷雾、出生分配、占领规则、联盟科技、PVE 强度、活动任务映射等策划可配内容。
- 所有可灰度、可调参、可投放、可替换旧目标的数值项。
- 字段含义与填表要点，帮助策划准备 Excel。

## 本文档不包含

| 类型 | 示例 | 说明 |
|------|------|------|
| 玩家存档 | 玩家当前坐标、玩家个人保护罩截止时间、玩家 KVK 战场状态 | 运行时持久化，由研发定义 |
| 联盟运行时 | 联盟当前堡垒归属集合、当前龙巢失效状态、战斗队列 | 服务端状态，不进策划配置表 |
| 战斗协议 | 发起攻击请求、战斗结算包、地图对象同步协议 | 技术派生文档维护 |
| 数据库结构 | 堡垒归属表、龙巢状态表、迷雾状态表 | 技术派生文档维护 |
| QA 用例 | 测试步骤、测试账号、验收清单 | QA 文档维护 |
| BI 埋点 | 事件名、字段名、上报时机 | BI 日志需求文档维护 |

# 地图基础配置

## `MapBasic`

| 字段 | 类型 | 说明 | 填表要点 |
|------|------|------|----------|
| `map_id` | int/string | 新服大地图模板 ID | 与旧服地图模板区分 |
| `map_name` | string | 地图模板名称 | 仅策划识别或后台展示 |
| `width` | int | 地图宽度 | 初始 7200 |
| `height` | int | 地图高度 | 初始 7200 |
| `grid_size` | int | 单格尺寸 | 初始 300 |
| `grid_count_x` | int | 横向方格数 | 初始 24 |
| `grid_count_y` | int | 纵向方格数 | 初始 24 |
| `enabled_server_type` | enum | 启用服务器类型 | 仅新服模板启用 |
| `min_client_version` | string | 最低客户端版本 | 用于老客户端拦截或强更 |

## `MapRegion`

| 字段 | 类型 | 说明 | 填表要点 |
|------|------|------|----------|
| `region_id` | int/string | 分区 ID | 出生区、中间圈、中心圈、王座区等 |
| `region_type` | enum | 分区类型 | `spawn` / `middle` / `center` / `throne` |
| `region_name` | string | 分区名称 | 后台识别；展示文案走多语言 |
| `fog_layer` | int | 对应迷雾层级 | 0/1/2 |
| `pve_level_group` | int/string | PVE 强度组 | 关联 `PveDistribution` |
| `grid_range` | string | 分区覆盖格子或多边形范围 | 可按项目地图工具格式填写 |
| `is_birth_available` | bool | 是否允许出生落城 | 仅出生区为是 |

# 堡垒配置

## `FortressGrid`

| 字段 | 类型 | 说明 | 填表要点 |
|------|------|------|----------|
| `grid_id` | int/string | 堡垒方格唯一 ID | 全地图唯一 |
| `map_id` | int/string | 所属地图模板 | 关联 `MapBasic` |
| `grid_x` | int | 方格横向序号 | 与地图工具一致 |
| `grid_y` | int | 方格纵向序号 | 与地图工具一致 |
| `center_pos` | string | 方格中心坐标 | 用于展示和寻路 |
| `region_id` | int/string | 所属分区 | 关联 `MapRegion` |
| `fortress_type` | enum | 堡垒类型 | 初始共享、普通、王座关联等 |
| `is_occupiable` | bool | 是否可被联盟占领 | 初始共享堡垒为否 |
| `is_initial_shared` | bool | 是否初始共享堡垒 | 首战锚点 |
| `altar_id` | int/string | 附属圣坛 ID | 无则为空 |
| `pve_level_group` | int/string | PVE 强度组 | 可继承分区或单独覆盖 |
| `fog_layer` | int | 迷雾层级 | 可继承分区或单独覆盖 |
| `display_priority` | int | 地图展示优先级 | 用于重叠图标处理 |

## `InitialSharedFortress`

| 字段 | 类型 | 说明 | 填表要点 |
|------|------|------|----------|
| `shared_id` | int/string | 初始共享堡垒配置 ID | 全表唯一 |
| `grid_id` | int/string | 对应堡垒方格 | 必须是不可占领共享堡垒 |
| `spawn_region_id` | int/string | 所属出生区 | 保证每个出生区都有足够锚点 |
| `first_attack_ring` | int | 首战可攻击圈层 | 初始为 1 |
| `enabled` | bool | 是否启用 | 便于灰度调整 |

## `FortressAdjacency`

| 字段 | 类型 | 说明 | 填表要点 |
|------|------|------|----------|
| `grid_id` | int/string | 当前堡垒方格 ID | 关联 `FortressGrid` |
| `adjacent_grid_id` | int/string | 相邻堡垒方格 ID | 互邻关系需校验 |
| `adjacency_type` | enum | 相邻类型 | 四邻、六邻或特殊通路 |
| `is_attack_path` | bool | 是否提供攻击资格 | 阻挡区或特殊边界可关闭 |
| `path_group` | int/string | 通路组 | 用于特殊中心区通路控制 |

# 占领规则配置

## `FortressOccupyRule`

| 字段 | 类型 | 说明 | 填表要点 |
|------|------|------|----------|
| `rule_id` | int/string | 占领规则 ID | 可按地图或区域拆分 |
| `fortress_type` | enum | 适用堡垒类型 | 普通、王座关联等 |
| `region_id` | int/string | 适用分区 | 可为空表示全局 |
| `base_occupy_time` | int | 基础占领时间 | 秒或分钟，按项目标准 |
| `first_attack_shield_time` | int | 首战免战时间 | 建议 12-24 小时 |
| `break_shield_on_attack` | bool | 免战期间主动进攻是否解除免战 | 待拍板项 |
| `kvk_occupy_time_multiplier` | float | KVK 期间原服占领时间倍率 | 建议 2-3 |
| `alliance_fortress_limit_group` | int/string | 堡垒上限组 | 关联联盟科技 |
| `allow_attack_owned_first_ring` | bool | 首战是否允许攻击已归属堡垒 | 默认允许非免战目标 |
| `dissolve_to_neutral_delay` | int | 联盟解散后转中立延迟 | 主案建议 24 小时，正式值由玩法策划拍板 |
| `rebuild_first_attack_ban_days` | int | 联盟解散重建后禁止首战资格的时间窗口 | 建议 30 天，防止解散重建蹭首战免战 |
| `rebuild_ban_judge_type` | enum | 首战防滥用判定口径 | 按盟主账号历史解散记录 / 按核心成员重合度 |
| `first_attack_audit_log_enabled` | bool | 是否记录首战免战审计日志 | 建议默认开启，记录触发联盟/账号/时间/目标堡垒 |

# 填表自检

- [ ] 新服地图模板与旧服地图模板已明确隔离。
- [ ] 每个出生区至少配置可用的初始共享堡垒。
- [ ] 初始共享堡垒不可被占领，但能提供首战可攻击目标。
- [ ] 每个普通堡垒都有正确的相邻关系，互邻关系已校验。
- [ ] 龙巢的相邻堡垒列表与地图交叉点一致。
- [ ] 圣坛只配置在可占领堡垒内。
- [ ] 迷雾层级开放时间不早于对应玩法目标需要的开放时间。
- [ ] 王座可攻击时间不早于中心圈开放时间。
- [ ] KVK 期间普通堡垒占领时间倍率已配置，王座不受该倍率影响。
- [ ] 旧方尖碑、中心堡垒、远征堡垒相关任务和活动计数均已替换或禁用。
- [ ] 老客户端最低版本和降级策略已确认。
