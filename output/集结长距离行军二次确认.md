# 简介

## 设计目的

玩家发起或加入集结前，提醒其关注过长的行军耗时，减少因忽略距离而误发起、误加入集结的情况。

## 功能简述

集结列表提前提示目标距离较远。玩家手动发起或加入集结时，若相关路段的预计行军时间超过常量配置的阈值，则在选择部队并点击“出发”后弹出二次确认。玩家确认后继续原操作，取消则保留当前选择。

# 关键决策

| 维度 | 决策 |
|---|---|
| 适用对象 | 所有集结类型的手动发起、手动加入操作 |
| 时间判定 | 按各路段分别判断预计行军时间，发起与加入共用一个常量阈值 |
| 提示层级 | 集结列表用“距离较远”做前置提示，最终是否弹窗以点击“出发”时的实时计算结果为准 |
| 交付形式 | 本需求按小型需求单文档交付，界面规则与效果图直接写入本文 |

# 详细规则

## 时间口径与阈值

- **行军时间口径**
  - 集结点指集结发起者所在地。
  - 使用当前部队与行军加成下、对应路段的预计行军时间，计入距离带来的行军耗时，**不计入集结等待时间**。
  - 加入时涉及的两段行军时间独立判断，**不相加**。
- **阈值配置**
  - 发起与加入共用一个“集结行军二次确认时间阈值”常量，初始配置为 **5 分钟（300 秒）**。
  - 仅当预计行军时间**严格大于阈值**时触发；等于或小于阈值时继续原流程。

## 触发规则

本规则适用于所有集结类型的手动发起和手动加入；自动加入不触发二次确认，沿用现有规则。玩家完成部队选择并点击“出发”时，使用当前选择与最新状态重新计算预计行军时间，再按下表判断。

| 操作 | 判断路段 | 弹窗条件 |
|---|---|---|
| 手动发起集结 | 集结点 → 攻击目标 | 该路段预计行军时间超过阈值 |
| 手动加入集结 | 加入者所在地 → 集结点；集结点 → 攻击目标 | 任意一段预计行军时间超过阈值 |

- **弹出次数**
  - 同一次加入操作中，两段均超过阈值时只弹出一次确认。
  - 每次符合条件的手动操作均需确认；上一次的确认不免除后续操作的提示。
- **执行顺序**
  - 未超过阈值时，不弹窗，直接进入现有发起或加入流程。
  - 超过阈值时，先弹出二次确认；玩家点击“确定”后才提交本次发起或加入操作。

## 集结列表远距离提示

- 集结可加入列表展示每个集结时，计算“集结点 → 攻击目标”的预计行军时间；超过同一常量阈值时显示 **“距离较远”**。
- 此处只判断集结出发后的路段。“加入者所在地 → 集结点”受加入者所选部队影响，在玩家点击“出发”时参与最终判断。
- “距离较远”与现有“优势明显”属于同级提示：字号、字重和所在信息行保持一致，文字使用橙红色，不增加底框或标签底图。
- 两项同时满足时并列展示，顺序为“优势明显”“距离较远”。列表提示只用于提前告知，不替代最终二次确认判定。

## 确认与取消

- **确认继续**
  - 点击“确定”关闭弹窗，提交本次发起或加入操作，沿用现有操作条件校验。
  - 校验通过时执行原操作；校验失败时不执行，并按现有规则反馈失败原因。
- **取消操作**
  - 点击“取消”或右上角关闭按钮时关闭弹窗，不执行本次发起或加入，并停留在部队选择界面，保留当前选择。
  - 玩家再次提交操作时，按届时的预计行军时间重新判断。
- **弹窗期间集结状态变化**
  - 若出现集结已满、解散等情况，玩家确认后仍按现有规则校验并反馈。

# 界面设计

## 集结可加入列表

在现有提示区域增加橙红色文字“距离较远”，与“优势明显”保持同一视觉层级，不增加底框。

![集结列表距离较远提示效果](ui-design/rally-long-march-confirm/rally-list-distance-marker-v2.png)

## 加入集结二次确认

- 弹窗沿用通用二次确认样式：标题“提示”，右上角关闭按钮，左侧蓝色“取消”，右侧黄色“确定”。
- 正文文案：**预计本次集结行军时间较长，是否确认加入集结？**
- 不显示“不再提醒”选项。

![加入集结二次确认效果](ui-design/rally-long-march-confirm/join-rally-confirm.png)

## 发起集结二次确认

- 弹窗样式与加入集结一致。
- 正文文案：**预计本次集结行军时间较长，是否确认发起集结？**
- 不显示“不再提醒”选项。

![发起集结二次确认效果](ui-design/rally-long-march-confirm/launch-rally-confirm.png)
