# 羁绊系统调整 · 开发 Checklist

> **定位**：根据 `英雄羁绊系统调整策划案.md` 拆解的开发与验收清单。本文只列交付事项和完成标准，不替代 GDD、技术方案或测试用例。

# 交付范围

- [ ] 羁绊战力在配置等级处封顶，总羁绊等级继续累计。
- [ ] 达到门槛后解锁机制功能，不自动选择默认机制。
- [ ] 每个编队独立保存一个机制，并支持未选择、有效、失效三种业务状态。
- [ ] 超额等级按成长间隔换算机制效果，并受各参数独立上限约束。
- [ ] 机制更换只影响下一次出征；已出征部队使用出征快照。
- [ ] 完成羁绊页、机制页和机制选择弹窗三处界面调整。
- [ ] 完成未选择、失效状态的机制页签红点闭环。

# 配置

- [ ] 增加羁绊战力等级上限、机制解锁门槛、成长等级间隔和单次成长值配置。
- [ ] 增加机制定义配置，覆盖名称、说明、图标、排序、类型和开放状态。
- [ ] 增加机制参数配置，支持固定参数、成长参数、独立上限和展示精度。
- [ ] 增加机制来源配置，支持通用来源、当前主将来源和指定英雄上阵条件。
- [ ] 配置暴击、闪避、连击、额外伤害、反击、克制强化六种机制。
- [ ] 删除或停用“破甲”旧示例，确保界面、配置和文案统一使用“闪避”。
- [ ] 校验同机制多来源只影响可用性，不叠加数值。
- [ ] 校验机制关闭、来源关闭和非法配置均能进入可诊断的失效状态。

# 客户端

## 羁绊页

- [ ] 主进度展示有效羁绊等级；超过上限时仍显示满级进度，例如 `660/660`。
- [ ] 达到上限后展示超额等级用于机制成长的说明。
- [ ] 羁绊战力加成沿用现有格式，并停止上限后的继续增长。
- [ ] 保留英雄详情入口及现有羁绊英雄展示规则。

## 机制页

- [ ] 机制页签在未解锁时可见，并展示动态解锁等级提示。
- [ ] 已解锁未选择时展示空状态、选择引导和红点。
- [ ] 有效状态展示机制图标、名称及代入实际参数后的完整说明。
- [ ] 失效状态展示原机制、“已失效”和可恢复条件。
- [ ] 下一成长区域按总羁绊等级展示，例如 `685/690`。
- [ ] 当前机制达到参数上限时展示“已达效果上限”，不展示伪下一节点。
- [ ] 更换按钮只在功能已解锁时可用。
- [ ] 持续展示“更换结果仅对下一次出征生效”。

## 机制选择弹窗

- [ ] 按配置顺序展示机制卡片，锁定项保留原位置。
- [ ] 支持普通可选、当前已选择、临时选择、锁定、已保存但失效状态。
- [ ] 点击卡片只修改临时选择，不立即覆盖服务器选择。
- [ ] 点击锁定卡片不改变临时选择，并展示动态英雄解锁提示。
- [ ] 点击确认时提交最后一次临时选择；关闭弹窗放弃修改。
- [ ] 保存失败或超时后以服务器状态为准，不以本地高亮冒充成功。

## 红点

- [ ] 功能解锁且当前编队未选择机制时点亮【机制】页签红点。
- [ ] 已保存机制失效时点亮红点。
- [ ] 保存有效机制或失效机制自动恢复时熄灭红点。
- [ ] 仅做临时选择、存在锁定卡片或机制达到上限时不改变红点。
- [ ] 在解锁、切换编队、调整阵容/主将、确认选择、登录和重连时刷新。

# 服务器与玩家数据

- [ ] 按现有英雄星级规则计算并保存总羁绊等级，等级只增不减。
- [ ] 羁绊战力读取有效羁绊等级，不读取超额等级。
- [ ] 为每个编队保存独立机制选择，空值表示未选择。
- [ ] 确认选择时校验功能解锁、机制开放、来源和指定英雄条件。
- [ ] 重复提交相同选择按幂等成功处理。
- [ ] 阵容或主将变化时重新判断已保存机制有效性，但不清空选择。
- [ ] 任一来源仍有效时保持机制有效；所有来源失效时才标记失效。
- [ ] 条件恢复且玩家未改选时自动恢复原机制。
- [ ] 老玩家上线时不自动分配机制；达到门槛的编队初始化为空选择。
- [ ] 编队机制选择参与转服/跨服所需的玩家数据迁移。

# 战斗与出征

- [ ] 出征时重新校验当前编队机制有效性。
- [ ] 有效时固化机制类型、固定参数、成长参数最终值和必要版本信息。
- [ ] 未选择或失效时生成“无有效机制”快照，不阻止出征。
- [ ] 已出征部队不因英雄升星、机制切换、阵容变化、条件恢复或配置热更而改变。
- [ ] 暴击按配置概率将该次攻击总伤害变为配置倍率，不按额外伤害重复相加。
- [ ] 闪避成功时本次攻击伤害为 0；非伤害控制按原技能规则处理。
- [ ] 连击产生的追加攻击不能再次触发连击。
- [ ] 额外伤害以本次实际伤害为基数，追加伤害不能再次触发机制。
- [ ] 反击以实际承受伤害为基数；伤害为 0 时不反击，反击不能递归触发。
- [ ] 克制强化同时支持克制增伤与非克制减伤，两个参数分别封顶。
- [ ] 与原英雄技能、Buff 或同类效果同时存在时沿用现有战斗系统合并与互斥规则。

# 美术与界面资源

- [ ] 确认六种机制正式图标及选中、普通、锁定、失效表现。
- [ ] 确认机制页未解锁、未选择、有效、失效、已封顶五类状态资源。
- [ ] 确认选择卡片的勾选、高亮边框、锁定图标和状态标签。
- [ ] 确认羁绊页满级装饰与机制页成长进度条表现。
- [ ] 资源命名、图集归属与适配规格由美术和客户端资源规范确定。

# 多语言

- [ ] 新增六种机制名称、完整说明和卡片短说明 KEY。
- [ ] 新增机制等级解锁提示、英雄条件锁定提示、失效提示和保存成功提示 KEY。
- [ ] 所有动态文案占位符从 `{0}` 起连续编号，并在多语言版本保持数量与顺序一致。
- [ ] 正式界面不得显示 `X%`、`{英雄名}` 等设计占位符。
- [ ] 百分比文案使用自然语序，例如“有 2% 概率”，不显示“有+2%概率”。

# 数据兼容与上线

- [ ] 上线时根据既有英雄星级数据计算总羁绊等级和超额等级。
- [ ] 验证已有玩家羁绊战力不会因总等级继续累计而突破配置上限。
- [ ] 旧客户端不能发起机制选择，但缺少新字段时不能导致出征异常。
- [ ] 调整成长参数、机制上限和来源配置后，只影响新出征快照。
- [ ] 提高解锁门槛时保留历史选择并暂停生效；重新满足后恢复。
- [ ] 关闭机制或来源时保留历史选择并标记失效，不自动替换。
- [ ] 断线重连后以服务器已保存选择为准，未确认临时选择不恢复。

# 联调验收

- [ ] 总等级 659：机制未解锁、无机制红点、无法打开选择弹窗。
- [ ] 总等级 660：机制解锁、成长值为 0、未选择时允许出征且无机制效果。
- [ ] 总等级 669：成长值仍为 0，下一节点显示 670。
- [ ] 总等级 670：成长参数增加 1 个百分点。
- [ ] 总等级 685：成长参数增加 2 个百分点，下一节点显示 `685/690`。
- [ ] 同一玩家不同编队保存不同机制，互不覆盖。
- [ ] 关闭选择弹窗后原选择不变；确认后只影响下一次新出征。
- [ ] 当前机制条件失效后保留选择、点亮红点、允许出征但新部队无效果。
- [ ] 条件恢复后原机制自动生效并熄灭红点。
- [ ] 机制通过任一重复来源仍有效时不得误判失效。
- [ ] 切换到已封顶机制显示上限状态；切换到未封顶机制重新显示下一节点。
- [ ] 配置热更前已出征部队继续使用旧快照，热更后新部队使用新参数。
- [ ] 连击、反击和追加伤害在高概率配置下仍不会形成无限触发链。

# 本期不处理

- [ ] 不增加机制养成资源和主动升级操作。
- [ ] 不支持自由分配超额等级或效果点。
- [ ] 不支持同一编队同时生效多个机制。
- [ ] 不支持机制预设方案、自动推荐或首次解锁自动选择。
- [ ] 不回溯修改已出征部队的机制快照。
