# 秘宝系统扩展 · 仓库分解版

2026-09-22，主案 v2.1。此目录替代“碎片直升版”的当前界面方案。

## 已确认规则

- 特技升级只消耗通用秘宝碎片，取消同名秘宝材料入口。
- 秘宝主界面选中区展示该件固定特技，点击“特技升级”直接进入升级弹窗。
- 新增秘宝仓库，支持品质筛选、多选分解和两类资源返还预览；已装备秘宝不可直接勾选分解。
- 所有橙色秘宝分解返还碎片：基础碎片价值 + 累计升级投入，全额返还。
- 低品质秘宝只返还破碎大陆金币，不产出秘宝碎片。
- 通用规则汇总至 i 说明；确认分解时展示本次资源结果与橙色返还构成。
