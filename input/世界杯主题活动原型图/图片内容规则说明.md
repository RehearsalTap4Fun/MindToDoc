# 世界杯主题活动原型图标注说明
> 标注方式：原图只添加红色编号圆点；说明文本单独在下方表格维护。坐标和元素归类基于当前截图视觉识别，后续写入钉钉文档前建议逐图复核。
## 主界面
![主界面 标注图](标注/主界面_标注.png)
| 标号 | 图中内容 | 规则说明 |
|---:|---|---|
| 1 | 顶部资源栏：金币、钻石、体力等资源 | 资源数值由服务端下发；体力不足时主线入口应提示不足或置灰。 |
| 2 | 中央球员形象和当前队服 | 展示玩家当前角色与队伍外观；外观修改后需要同步刷新。 |
| 3 | 评分 / 进球 / 助攻三项数据 | 统计值来自活动累计数据；不在前端本地推导。 |
| 4 | 黄色按钮“下一场比赛” | 点击进入当前可挑战关卡或战前界面；需校验体力、关卡解锁状态。 |
| 5 | 底部主导航，当前停留在“开始”页 | 底部导航用于商店、比赛、开始、赛程、榜单等模块切换，红点表示有待处理事项。 |
