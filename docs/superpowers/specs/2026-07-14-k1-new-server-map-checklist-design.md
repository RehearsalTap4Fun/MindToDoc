# K1 新服大地图重构精简版开发 Checklist 设计

## 目标

基于最新同步的 `output/K1新服大地图重构功能策划案.md`，生成一份可用于早期工作量评估和跨职能排期的精简版开发 Checklist Excel。

精简版不以任务条数定义粒度。每项任务应对应某一职能在一个完整功能模块上的可交付成果；同一模块内高度相关的功能点合并为一项，关键范围、依赖和验收边界写入备注。

## 输入与输出

- 输入：`output/K1新服大地图重构功能策划案.md`
- 输出：`output/K1新服大地图重构_开发checklist_精简版.xlsx`
- 线上钉钉文档仅作为最新内容来源，本地已同步主案作为生成时的单一输入，避免生成过程中版本漂移。

## 拆解结构

按主案的可交付模块组织任务：

1. 配置与公共依赖
2. 地图结构与出生分配
3. 堡垒占领与联盟领地
4. 龙巢、圣坛、王座及地图对象
5. 迷雾与地图表现
6. 联盟系统适配
7. KVK 往返与兼容
8. 任务、成就、活动、排行与引导替换
9. 数据兼容与版本隔离

## 职能范围

采用生成器默认的五类职能：数值策划、UI、原画&3D、客户端、服务器。

- 数值策划：配置定义、投放规则、任务与文本口径。
- UI：战略地图、缩略地图、状态与反馈界面设计。
- 原画&3D：地图区域、迷雾、战略对象及必要表现资源。
- 客户端：地图展示、交互、状态刷新、入口、红点与本地校验。
- 服务器：归属、相邻资格、战斗结算、迷雾进度、联盟与跨场景数据处理。

某模块确实没有该职能的独立交付物时不强行生成任务。

## 任务字段

每项任务包含：模块、任务描述、职能、优先级、备注。

备注统一说明：

- 覆盖的关键功能点；
- 前置依赖或联调对象；
- 可验证的完成边界；
- 复用既有系统或本期不处理的范围。

## 优先级

- P0：主流程、配置契约、地图与归属数据、核心战斗/结算、版本隔离等阻塞项。
- P1：缩略地图、红点、活动排行替换、表现完善等重要但可并行项。
- P2：不影响首版闭环的纯体验增强；最新主案未明确的增强项不自行补入。

## 工作簿结构与验收

工作簿包含总表、统计总览，以及五个职能分表。总表按模块分组，支持筛选；统计总览汇总各职能及优先级数量。

交付前检查：

- 主案各模块均有对应任务或明确说明无需任务；
- 配置、客户端、服务器之间的关键依赖不缺失；
- 不把现有系统复用项误拆成重做任务；
- 不引入主案未定义的功能和数值；
- 所有职能分表与总表统计一致；
- 工作簿无公式错误，所有工作表完成视觉检查。
