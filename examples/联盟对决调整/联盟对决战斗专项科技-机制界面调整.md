# 适用关系

本文记录战争机器为英雄羁绊机制界面增加第二机制栏的增量规则。羁绊系统原有页面结构、开放条件、机制解锁、账号机制等级、选择与升级规则继续以《羁绊系统调整-界面规则》为准；未在本文列出的原界面规则保持不变。

# 子界面清单

| 界面 ID | 调整内容 |
|---|---|
| `HeroBond_Mechanism` | 增加双机制选项卡及第二栏状态 |
| `HeroBond_MechanismSelect` | 按目标栏位选择机制，限制两栏重复选择 |
| `Lineup_MechanismEntry` | 展示当前队伍已装备的机制 |

|---:|---|---|---|

## 选项卡布局

- 两个选项卡等宽并扩大点击区域，不单独增加“机制栏 1／机制栏 2”文字。
- 机制名称位于等级上方，最多显示两行；按本地化文本自动换行，不使用省略号挤压等级区域。
- “机制名字预留”只用于效果图占位，正式界面读取机制配置名称，不新增对应本地化文本。
- 第二栏未解锁时显示锁定状态和解锁提示；已解锁未装备时显示空状态，不自动填入机制。

## 栏位状态与交互

| 栏位状态 | 选项卡表现 | 点击结果 |
|---|---|---|
| 已装备、当前选中 | 亮色底板、高亮描边、底部选中条；满足条件时显示升级标志 | 保持选中；点击图标或名称打开目标栏位选择弹窗 |
| 已装备、未选中 | 低亮度底板；满足条件时仍显示升级标志 | 切换选中项并刷新详情与升级区 |
| 栏位已解锁、未装备 | 空状态；存在可装配机制时计入待选择红点 | 选中后显示装配引导；点击图标或名称打开目标栏位选择弹窗 |
| 第二栏未解锁 | 锁定样式，不显示升级标志 | 展示“研究战争机器【队伍 {0}·第二机制栏】后解锁”，不打开选择弹窗 |

- 本表只定义栏位状态；“可装配”只用于机制卡片，不用于描述空栏位。两栏分别保存，可以独立更换或留空。
- 两栏不能装备相同机制；第二栏不复制机制等级或成长记录。
- 机制页签红点在任一已开放栏位为空且存在可装配机制，或任一已装备机制可升级时点亮；条件全部消除后熄灭。
- 机制更换与升级只影响下一次新出征，已出征部队继续使用原快照。

# 机制选择弹窗

- 打开弹窗前先确定当前选项卡对应的目标栏位；弹窗标题、卡片布局、临时选择和确认流程沿用原规则。

| 机制卡片状态 | 判定 | 卡片表现 | 点击结果 |
|---|---|---|---|
| 未解锁 | 机制自身尚未满足解锁条件 | 整卡置灰，显示锁标志与动态解锁条件 | 不改变临时选择 |
| 可装配 | 机制已解锁，且当前目标栏与另一栏均未装备该机制 | 正常亮度，不显示勾选或装备标志 | 切换为当前临时选择 |
| 已装备 | 当前目标栏已经装备该机制 | 高亮描边，显示勾选与“已装备” | 保持当前临时选择 |
| 另一栏已装备 | 当前队伍的另一机制栏已经装备该机制 | 保持原排序，整卡置灰并显示“另一栏已装备” | 不改变临时选择 |

- 四种机制卡片状态按打开弹窗时的目标栏位判定；切换目标栏位后重新计算。“可装配”与“已装备”不得使用相同的高亮、勾选或状态文案。
- 确认时校验目标栏已开放、机制已解锁且未被另一栏装备。校验失败时保留原服务器装备并展示失败原因。
- 弹窗只负责选择机制，不增加升级入口或可升级标志。

# 编队页面—机制入口

- 当前队伍最多展示两个已装备机制的标准图标；第二栏未解锁或栏位为空时不显示空图标。
- 点击机制区域进入英雄羁绊—机制页签。存在已开放空栏时默认选中空栏，否则默认选中第一栏。
- 编队入口红点复用机制页签的聚合结果。
