# K1新服大地图重构 · 配置表结构（数值/关卡/活动策划填表）

> **定位**：仅描述数值、关卡、地图、活动策划在 Excel 中需要填写的配置表字段。  
> **规则依据**：主策划案 [K1新服大地图重构.md](K1新服大地图重构.md)。  
> **边界**：本文不定义玩家存档、运行时状态、接口协议、DB 字段和服务端状态机。

---

## 文档边界

### 本文档包含

- 新服地图模板、方格、分区、相邻关系、迷雾层级和开放时间。
- 堡垒类型、初始共享堡垒、王座方格、免战和 KVK 期间倍率等可调参数。
- 龙巢、火龙巢、圣坛、恶魔守卫、PVE 强度和刷新参数。
- 联盟科技新增分支的等级、上限和消耗引用。
- 新服任务、成就、活动和排行计数的配置口径。
- 红点、引导、提示和多语言 key 的配置引用。

### 本文档不包含

| 类型 | 示例 | 说明 |
|------|------|------|
| 玩家存档 | 玩家所在方格、当前保护罩、个人任务进度 | 运行时持久化，由服务端定义 |
| 联盟运行时 | 当前占领堡垒列表、龙巢失效状态、战斗中的目标 | 运行时状态，不进策划静态表 |
| 战斗协议 | 出兵参数、战报结构、伤兵结算字段 | 研发派生文档维护 |
| 接口/DB | 地图查询接口、占领请求、归属表结构 | 技术方案维护 |
| 客户端组件 | UI 节点、prefab、组件 ID | 界面标注或客户端文档维护 |

## 配置表概览

### 公共 / 外部依赖

| 类型 | 典型表 / 机制 | 本功能用法 | 策划动作 |
|------|----------------|------------|----------|
| 全局常量 | `ConstConfig.xlsx` / `Config.xlsx` | 开服天数、首战免战、KVK 期间倍率、出生选择期等全局参数 | 新增 K1 新服地图常量组 |
| 开关 | `Switch.xlsx` | 控制新服地图模板是否启用 | 新增新服模板开关 |
| 服务器/赛季 | `ServerGroup.xlsx` / `CompetitionSeason.xlsx` | 判断新服模板、服务器创建时间、KVK 周期和分组 | 增加新服地图模板引用 |
| KVK 设置 | `KvkConfig.xlsx` | 复用 KVK 地图认知与 KVK 往返规则，不改 KVK 核心 | 仅校验引用，不复制 KVK 活动配置 |
| 联盟 | `Union.xlsx` / `UnionStore.xlsx` | 联盟权限、科技、领地、商店、礼物等现有机制 | 新增科技分支与领地判定相关配置 |
| NPC / 怪物 | `NpcTroopClass.xlsx` / `D2NpcTroopClass.xlsx` / `Monster.xlsx` | 野怪、泰坦、恶魔守卫、龙巢守卫强度引用 | 配置新服地图等级段和刷新点 |
| 行军 | `MarchType.xlsx` | 堡垒战、龙巢战、王座战行军类型复用或新增 | 校验是否需要新增行军类型 |
| 任务/成就 | `NewQuest.xlsx` / `DailyQuestNew.xlsx` / `ChapterQuest.xlsx` | 替换旧地图任务目标 | 新增新服任务链与目标类型引用 |
| 活动任务 | `ActivityQuest.xlsx` | 活动任务中地图目标替换 | 替换方尖碑、联盟堡垒、龙巢连接类目标 |
| 排行榜 | `ActivityRank.xlsx` | 新增堡垒数、龙巢数、王座积分、领地方格数排行 | 新增排行口径或活动分组 |
| 邮件/通知 | `Mail.xlsx` / `MailModule.xlsx` / `Push.xlsx` / `ChatSystemNotification` | 堡垒被攻占、王座开放、迷雾开放等通知 | 新增通知模板并做旧客户端兼容 |
| 引导 | `Guide.xlsx` / `GoalGuide` | 首次占领堡垒、查看可攻击目标、迷雾开放引导 | 新增新服地图引导链 |
| 物品/货币 | `Item.xlsx` / `VM.xlsx` | 奖励、消耗、礼包引用 | 只引用，不在本功能新建经济体系 |

## 新服地图模板

### `NewServerMapTemplateCfg`

| 字段 | 类型 | 说明 | 填表要点 |
|------|------|------|----------|
| `TemplateID` | int | 新服地图模板 ID | 新服服务器引用；老服不引用 |
| `TemplateName` | string | 模板备注名 | 仅策划识别 |
| `EnableSwitchID` | int | 启用开关 | 引用 `Switch.xlsx` |
| `MapWidth` | int | 地图宽度 | 固定 7200 |
| `MapHeight` | int | 地图高度 | 固定 7200 |
| `GridSize` | int | 方格边长 | 固定 300 |
| `GridRow` | int | 行数 | 固定 24 |
| `GridCol` | int | 列数 | 固定 24 |
| `ServerScope` | enum | 生效服务器范围 | 仅新开服务器 |
| `OldServerFallback` | enum | 老服处理 | 固定不迁移/不启用 |
| `Remark` | string | 备注 | 写明灰度批次或版本 |

## 地图分区与迷雾

### `NewServerMapZoneCfg`

| 字段 | 类型 | 说明 | 填表要点 |
|------|------|------|----------|
| `ZoneID` | int | 分区 ID | 出生区、中间圈、中心圈、王座区分别配置 |
| `TemplateID` | int | 地图模板 ID | 关联 `NewServerMapTemplateCfg` |
| `ZoneType` | enum | 分区类型 | `BirthFan` / `MiddleRing` / `CenterRing` / `Throne` |
| `BirthFanIndex` | int | 出生扇形编号 | 非出生区填 0 |
| `FogLevel` | int | 迷雾层级 | 0/1/2 |
| `OpenDay` | int | 开服第几天开放 | 推荐 0、8、15、21，具体按灰度调整 |
| `CanBirth` | bool | 是否可出生 | 仅出生区为 true |
| `CanTeleport` | bool | 是否可迁入 | 迷雾开放后才生效 |
| `PveTier` | int | PVE 强度档 | 关联 PVE 刷新配置 |
| `DisplayPriority` | int | 地图显示优先级 | 用于区域提示 |

### `NewServerFogCfg`

| 字段 | 类型 | 说明 | 填表要点 |
|------|------|------|----------|
| `FogID` | int | 迷雾配置 ID | 唯一 |
| `TemplateID` | int | 地图模板 ID | 关联模板 |
| `FogLevel` | int | 迷雾层级 | 0/1/2 |
| `OpenType` | enum | 开放方式 | 推荐 `ServerOpenDay`；预留混合驱动 |
| `OpenDay` | int | 开服天数 | D8/D15/D21 等 |
| `PreviewVisible` | bool | 未开放时是否显示轮廓 | 推荐 true |
| `HideOwnerBeforeOpen` | bool | 未开放时隐藏归属 | 固定 true |
| `HideTypeBeforeOpen` | bool | 未开放时隐藏类型/等级 | 龙巢、圣坛推荐 true |
| `RedPointID` | int | 开放红点 | 可引用红点配置 |
| `NoticeMailID` | int | 开放通知/邮件 | 若无邮件填 0 |

## 填表约定

- 所有新服专用配置必须带 `TemplateID` 或服务器模板限制，避免误作用到老服。
- 坐标、相邻关系、迷雾层级、战略点归属关系属于高风险配置，上线后不建议热更；必须热更时需安排维护窗口。
- 新增任务、成就、通知、多语言参数属于客户端兼容风险，旧客户端必须有降级策略。
- 具体奖励内容、消耗数值和等级曲线由数值策划配置，主案只约束触发和归属规则。
- 新建多语言 key 使用 K1 功能名前缀，本文未接入 localization 查重源，所有 key 在正式填表前标记为“未查重”。
