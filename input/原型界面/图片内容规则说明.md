# 原型界面图片内容与规则说明

**来源图片**：`input/原型界面/*.png`  
**标注图片**：`input/原型界面/标注/*_标注.png`  
**关联开发文档**：`output/2026世界杯主题活动-开发文档.md`

## 1. 使用口径

- 本文件用于把 15 张原型截图转化为可开发规则说明，供客户端 UI、服务端状态和配置表对齐。
- 原图不改动；标注版图片另存到 `input/原型界面/标注/`。
- 表格中的“图中内容”只描述截图中实际可见的 UI、文案、图标或布局；规则推导只放在“规则说明”列。
- 截图中的数值、队名、轮次、奖励等均视为示例展示；正式值以配置表和服务端下发为准。
- 排名、合同、结算、资源变更均应以服务端结果为准，前端只负责展示与提交操作。

## 2. 全局 UI 与数据规则

| 规则项 | 说明 |
|---|---|
| 顶部资源栏 | 门票、钻石、金币、活动道具数量统一读取玩家资产。资源变化后需要刷新，不由单个界面自行推算最终值。 |
| 返回与关闭 | 返回按钮回到上一层；弹窗关闭不应改变已确认状态。流程型弹窗如训练完成、签约确认，需要明确关闭是否等同确认。 |
| 主按钮防连点 | 开球、确认签约、升级、倒带等会改变状态或扣资源的按钮必须防重复提交。 |
| 服务端权威 | 关卡结果、排名、合同档位、奖励到账、赛程状态均以服务端返回为准。 |
| 示例文案 | 英文标题、队名、轮次和奖励文案可替换为本地化配置，不能写死在界面逻辑里。 |
