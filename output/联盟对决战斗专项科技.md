# 简介

## 设计目的

战争机器以可组合的战斗机制成长替代单纯提高养成上限，为成熟玩家提供可感知的长期能力提升，并持续承接联盟对决荣誉勋章消耗。

本功能以已经确定的英雄羁绊机制为基础：羁绊系统默认提供队伍第一机制栏，并负责机制的解锁、账号共享等级与选择；**战争机器**负责逐队解锁第二机制栏，同时按弓、火、冰、哥布林四类队伍提供暴击、闪避和伤兵结果强化。

## 功能简述
- **战争机器科技**：沿用现有科技树布局模板，依次解锁队伍 1—5 的第二机制栏。
- **队伍类型强化**：重要节点提供弓、火、冰、哥布林的暴击或闪避；填充节点提供三类战斗结果被动。
- **羁绊机制结合**：第二栏与第一栏共用已解锁机制池和账号共享机制等级，同队两栏不能选择相同机制。
- **活动扩档**：联盟对决个人进度由 1—9 档扩展至 12 档，第 10—12 档增加荣誉勋章产出。

# 详细规则

## 开放与入口
- 在现有联盟对决科技界面增加第三页签“战争机器”。
- 玩家完成 T10 终点科技 `202301` 后开放研究；未完成时页签可见并可预览节点、阶段和开放条件。
- 开放不自动研究节点、不自动替任何队伍选择机制，也不改变羁绊功能自身是否已解锁。
- 原有两棵联盟对决科技树的节点、等级、消耗与存量记录全部保留。

## 战争机器科技树

| 阶段 | 阶段内容 | 核心节点奖励 |
|------|------------|------------------|
| 1 | 四类型暴击提升 | 解锁队伍 1 第二机制栏 |
| 2 | 四类型闪避提升 | 解锁队伍 2 第二机制栏 |
| 3 | 四类型额外恢复伤兵 | 解锁队伍 3 第二机制栏 |
| 4 | 四类型轻伤比例提升 | 解锁队伍 4 第二机制栏 |
| 5 | 四类型敌方重伤比例提升 | 解锁队伍 5 第二机制栏 |

## 与英雄羁绊机制结合

### 栏位与机制池
- 羁绊系统默认提供第一机制栏；五个核心节点分别为队伍 1—5 增加第二机制栏。
- 两栏共用当前队伍已经获得的羁绊机制解锁池，同一队伍两栏不能选择同一种机制
    - 一个栏位已选择的机制，在另一个栏位中显示为“另一栏已选择”并不可提交。
    - 两栏分别保存，可以独立更换或留空；第二栏解锁时初始为空，不自动填入机制。
- 羁绊机制页以机制图标、名称和等级展示两个机制选项卡；
    - 详情、五星英雄进度和升级按钮随当前选中项切换。
    - 第二栏未解锁时展示“研究战争机器【队伍 N·第二机制栏】后解锁”。
- 当前查看队伍存在已开放但未选择的机制栏，且存在可选机制时，出征需要二次确认提示
    - 保存选择后不再提示

## 出征快照与战斗生效
- 已出征后研究科技、更换机制、提升羁绊等级或调整配置，均不改变当前部队；
    - 重新出征后读取新值。
- 第二栏中的机制与第一栏中的同名机制使用完全相同的触发、递归限制、结算顺序和战斗范围。
- 机制栏来自战争机器核心科技，不改变羁绊机制自身的适用场景，放入第二栏后仍沿用该机制规则。

## 联盟对决个人进度第 10—12 档
- 沿用现有规则，纯配置新增

## 红点规则

| 红点 | 触发 | 消除 |
|------|------|------|
| 战争机器开放 | 首次完成 `202301` | 首次进入战争机器页签 |
| 科技可研究 | 前置科技等级和荣誉勋章均满足，节点未满级 | 研究完成、条件变化或节点满级 |
| 第二栏开放 | 对应队伍核心节点刚完成 | 进入羁绊机制页并查看对应队伍 |
| 第二栏待选择 | 当前队伍第二栏已开放、为空且存在可选机制 | 成功保存第二栏机制，或已无可选机制 |

## 数据兼容与边界

| 场景 | 处理 |
|------|------|
| 存量联盟对决科技 | 原两棵树完整保留；第三棵树默认未研究，不折算、不补偿 |
| 存量荣誉勋章 | 数量原样保留，可直接用于新科技 |
| 存量羁绊选择 | 原选择写入第一栏；第二栏按五个核心节点状态初始化为锁定或空 |
| 已出征部队 | 继续使用旧快照，返回并再次出征后读取新科技和第二栏 |
| 进行中联盟对决 | 不热增第 10—12 档，从新一轮活动统一启用 |
| 转服、跨服、合服 | 战争机器科技、核心节点权限和两栏选择随个人数据迁移 |
| 荣誉勋章不足 | 研究按钮禁用；不部分扣除、不提升等级 |
| 重复研究请求 | 仅首个有效请求扣费和升级，其余返回最终状态 |
| 核心节点完成但队伍未开放 | 保留权限；队伍槽位开放后直接显示第二栏 |
| 两栏选择相同机制 | 拒绝保存目标栏修改，原有两栏选择保持不变 |
| 配置热更调整前置等级 | 新研究按最新前置条件判断；已完成核心节点和已解锁第二栏不会回退 |
| 配置热更提高条件或关闭效果 | 不降低科技等级、不收回第二栏、不清空羁绊机制选择 |

# 界面设计

战争机器复用现有科技树与联盟对决个人进度布局；羁绊机制界面扩展第二栏及其状态。

| 模块 | 变更 |
|------|------|
| 联盟对决科技 | 增加“战争机器”页签，展示五阶段、四类型强化和五个核心节点 |
| 羁绊机制页 | 当前队伍显示第一栏、第二栏；第二栏支持锁定、空、已选择状态 |
| 机制选择弹窗 | 增加目标栏位信息和“另一栏已选择”不可选状态 |
| 联盟对决进度 | 增加第 4 页，展示第 10—12 档及 T10 锁定状态 |
