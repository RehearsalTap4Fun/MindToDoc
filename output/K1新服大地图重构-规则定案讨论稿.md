# 规则定案记录

## 2026-07-10 审核问题定案

| 维度 | 定案结论 |
|------|----------|
| 堡垒相邻拓扑 | 采用四邻，只认上、下、左、右相邻，不认对角相邻 |
| 起点堡垒在进攻中被夺 | 战斗继续结算；若进攻方获胜，部队立即返回，不增加该堡垒的占领时间 |
| 同目标并发进攻 | 允许多个联盟同时攻击同一堡垒；防守方同时面对所有进攻方，进攻方胜利后成为新的防守方，复用现有规则 |
| 飞地扩张 | 飞地仍属于联盟领地，可继续作为后续扩张起点 |
| 并发超过科技上限 | 拦截结算更晚的战斗所对应堡垒，不使其进入联盟占领集合，复用现有规则 |
| 新联盟判定 | 不定义“重建联盟”；新创建的联盟均视为新联盟，满足零堡垒条件时走新联盟首战规则 |
| 地图对象技术口径 | 龙巢、圣坛、堡垒、王座均复用既有对象类型；新地图重新配置实体，显示、战斗和占领规则复用既有实现 |
