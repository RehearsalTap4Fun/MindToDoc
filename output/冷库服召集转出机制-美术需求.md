# 新增资产清单

## 「推荐」标签徽标

| 项目 | 说明 |
|------|------|
| 用途 | 服务器条目、联盟条目角标；出现于申请迁入、联盟转移、个人转移三个页签的目标列表 |
| 判定 | 语言匹配、活跃规模 50–200、付费结构健康，三项同时满足才显示；联盟条目继承其目标服的标签结果，只需一套视觉，不必区分“服务器级”和“联盟级”两种样式 |
| 状态 | 常态展示图标（可选配文字）；无标签时不显示任何占位，不能让“无推荐”读成“劣质/警示” |
| 优先级 | P0（三个通道页签均依赖，属于本次唯一的通用新控件） |

## 冷库预告弹窗视觉

| 项目 | 说明 |
|------|------|
| 用途 | 预告期（关闭前 2 天）每日首次登录弹出，说明关闭时间、三通道开放时间，并持续显示距 D3 结束的服务器关闭倒计时 |
| 设计约束 | 需要传达“服务器即将关闭”的严重性，区别于日常公告/活动预告弹窗的庆典风格；但连续两天每天登录必弹，要在“紧迫感”与“骚扰感”之间取得平衡，不宜做成强干扰的全屏动效 |
| 组件 | 背景插画/图标（暗色调或警示色，非庆典风格）；【前往召集】按钮的置灰态（D1 前）与可点击态（D1 后）两种视觉；倒计时数字复用现有格式，仅需确认是否要专属强调色（见「待确认项」） |
| 优先级 | P0 |

# 复用清单（不产生新美术需求）

| 控件/资产 | 复用依据 |
|-----------|----------|
| 三通道页签框架、目标搜索输入框 | 沿用召集活动主页与目标服务器搜索既有控件 |
| 赛季分组折叠列表、国王头像/国旗/联盟资料卡 | 沿用联盟迁移/个人迁移既有列表控件 |
| 战力、星级数字格式 | 沿用既有数字格式，标注文档已注明“沿用原控件” |
| 倒计时数字组件 | 标注文档明确“数字倒计时沿用现有格式” |
| 二次确认弹窗（移除成员等） | 沿用既有二次确认交互与视觉 |
| 成员列表分组、职级图标、移除/恢复携带按钮 | 沿用既有联盟成员管理列表控件 |
| 落地服联盟推荐弹窗 | 通道③落地安置直接复用现有推荐弹窗，无改动 |

# 待确认项

- 冷库预告弹窗最终走“新插画”还是“复用现有公告弹窗模板 + 新文案 + 现有警示图标”，建议先评估客户端是否已有“服务器即将关闭/合服预告”一类模板可直接改文案，再决定是否新制作背景插画。
- 倒计时临近关闭（如最后 1 天/1 小时）是否需要专属强调色变化，需 UI 侧确认是否与现有召集倒计时的强调节奏冲突。
- 「推荐」徽标含文字时，多语言下的文本长度差异是否需要预留自适应宽度。
- 召集申请弹窗、召集发布与审批界面、活动规则弹窗三屏尚未收到截图，暂按复用现行界面处理；收图后若发现有新增控件需补充本文件。
