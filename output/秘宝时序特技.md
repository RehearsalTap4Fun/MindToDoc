# 简介

## 设计目的

现有秘宝以基础战力百分比为主，穿最高品质即最优。通过时序特技形成配装选择，通过碎片升级与分解回收形成持续成长。

## 功能简述

首批新增 12 件橙色秘宝，四个部位各有进攻、守御、续战三种特技。玩家获取秘宝、搭配主副将装备，使用通用秘宝碎片升级，闲置秘宝在现有背包中分解回收。

# 关键决策

| 维度 | 决策 |
|---|---|
| 战斗分工 | 契约负责单次攻击结算链，秘宝按战斗时机提供伤害、防护、战地回战及下一场效果 |
| 配装与存量 | 同节点不同特技可共同生效，同名取最高等级；存量秘宝保留原属性与词条 |
| 成长与回收 | 特技升级逐级消耗碎片，实际投入单独记账；橙色分解全额返还基础价值与升级投入 |

# 详细规则

## 秘宝与装备

- **秘宝属性**
    - 每件新秘宝带一条固定时序特技，同品质基础战力百分比与存量秘宝一致。特技等级只改变效果参数，不改变品质与基础战力百分比。
    - 存量秘宝保留基础属性及源系列连击、暴击、伤兵恢复、暴伤词条，沿用原触发方式；不参与时序特技升级，可按品质分解。
- **装备与展示**
    - 开放与四槽沿用现有秘宝系统，王国纪事解锁关联 D2 常量 1072；装备、卸下与替换沿用部队驻防限制，同部位换新自动卸旧，无消耗、无冷却。
    - 选择面板展示节点、方向、特技名称与等级；存量秘宝显示原词条。主界面保留角色与四槽，选中区仅显示该件秘宝的固定效果，点击特技升级直接打开升级弹窗。

## 公共战斗机制

### 节点与生效特技

| 节点 | 部位 | 触发条件 |
|---|---|---|
| 开战 | 指环 | 战斗建立，从第 1 回合起生效 |
| 战中 | 项链 | 我方可战兵力占我方开战兵力的比例降至特技阈值以下 |
| 追击 | 号角 | 敌方可战兵力占敌方开战兵力的比例降至特技阈值以下 |
| 战后 | 护符 | 真实交战形成胜负，本场伤亡结算后、伤兵入医院及部队回城处理前 |

- **生效选取**
    - 出征时汇总主将、第一副将、第二副将携带的新秘宝；同节点不同特技均可生效，同名仅取等级最高的一条。同级依次取主将、第一副将、第二副将；其他秘宝仍提供基础属性。
    - 每场、每支部队、每种特技最多触发一次。双方独立判定、互不抵消；战中与追击无先后依赖，可先追击，也可整场不触发战中。行军发起、取消、改向不产生特技效果。
- **集结与守城**
    - 集结的开战、战中、追击只取发起者部队的生效特技，成员不参与这三个节点；战后按各参与部队各自结算判定，授予效果归该部队。
    - 守城所取部队与同场契约一致。适用战斗类型按现有野战、攻城、集结、守城、对 NPC 等配置判断。

### 回合与接战冷却

- **回合**
    - 沿用每秒一回合的战斗节拍。开战与上一场授予的限时效果从本场第 1 回合起持续 N 回合；护身从触发后的下一回合起计 N 回合。
    - 免疫期间照常计数，中途加入的部队从加入起计；计满即失效，战斗结束清零，不因兵力回升重新开启。
- **接战冷却**
    - 部队每次接战记录敌方单位与时间；同部队与同一敌方在配置冷却内再接战，开战特技不触发。不同目标不受此限制。
    - 冷却记录保留至到期，回城、驻防、改向不清零；战中、追击、战后及已授予效果照常。

### 伤害、回战与阈值

- **计算基数**
    - 开战兵力为战斗建立时的可战兵力，本场固定，用作阈值分母。
    - 损失兵力指本场阵亡与尚未回战的伤兵；伤兵回战后立即恢复为可战兵力，从本场伤兵中扣除，不重复恢复，也不再进入医院。
    - 回战与恢复人数向下取整。一次性回战、恢复触发时不足 1 名伤兵，仍记为已触发；救护按单次伤兵计算，不足以回战 1 人则不回战、不累计。
- **伤害关系**
    - 先声、乘胜与契约额外伤害、克制强化、英雄技能的增伤按现有方式合并后一次乘入，不改变契约的暴击、连击判定。
    - 雷霆、斩杀形成独立伤害，享受生效中的先声、乘胜；不进入契约链，不触发反击、连击、暴击，也不被闪避。其实际伤害照常划分阵亡与伤兵，并影响阈值。
- **受伤结算顺序**
    - 免疫：护身生效时全额免疫，本次不再进入减伤与伤兵处理；我方攻击和其他判定照常。
    - 减伤：战阵、坚守、对攻方施加的压制及英雄技能、契约、科技的同类减伤相加，受配置合计上限约束后一次乘入。
    - 入账与回战：实际伤害扣减可战兵力，按现有比例划分阵亡、伤兵；救护在伤兵划分后立即回战。
    - 阈值：以结算后的兵力判定受方战中、攻方追击。触发的一次性伤害进入对方的同一结算流程，回战立即更新可战兵力；已完成的步骤不回算。
- **阈值判定**
    - 同次结算有多条满足条件时，战中按护身→重整→雷霆，追击按斩杀→压制→整队逐条处理，只检查携带且尚未触发的特技。
    - 每条触发前按当前兵力重新判定。回战后不再满足阈值的本次不触发，后续再次满足时仍可触发；已触发的不会因兵力恢复而重置。双方的连锁效果按各自部队结算顺序处理。

### 战后与连战窗口

- **真实交战**
    - 以全灭或撤退形成胜负，且敌方开战兵力不低于我方的配置比例。无胜负结束或敌方兵力不足时，战后特技不触发，其他节点正常结算。
    - 按各部队胜负及携带特技，先结算凯旋，再授予乘胜、坚守；被全灭的部队无法携带下一场效果。
- **授予与消耗**
    - 乘胜、坚守随部队移动。连战窗口从本场结束计时，进入窗口内的下一场战斗即消耗，无论下一场是否真实交战、有无胜负或是否立即被全灭，均不退还。
    - 窗口只限制进入下一场的时机。进入后按配置回合数生效；同一效果再次授予只刷新窗口，不叠加幅度、不延长回合。
    - 未在窗口内接战，或部队回城驻防、解散、全灭、迁服时，未消耗效果作废。

## 特技定义

以下为每条特技的唯一效果定义，公共叠加、结算、回合及取整规则见上节。A 为该特技该等级的比例，N 为回合数；具体参数按配置，等级示例集中列于文末。

| 节点／方向 | 特技 | 效果与独有条件 | 成长项／战报影响值 |
|---|---|---|---|
| 开战／进攻 | 先声 | 本场前 N 回合，普攻及雷霆、斩杀的成型伤害提高 A% | A、N／额外伤害 |
| 开战／守御 | 战阵 | 本场前 N 回合，我方受到的伤害降低 A% | A、N／减免伤害 |
| 开战／续战 | 救护 | 本场前 N 回合，每次新产生伤兵按 A% 立即回战 | A、N／回战人数 |
| 战中／进攻 | 雷霆 | 我方兵力低于阈值时，造成我方本场损失兵力×A% 的一次伤害；我方已全灭则不结算，伤害不超过敌方剩余兵力 | A／实际伤害 |
| 战中／守御 | 护身 | 我方兵力低于阈值时，从下一回合起免疫全部伤害 N 回合，含一次性伤害 | N／免疫伤害 |
| 战中／续战 | 重整 | 我方兵力低于阈值时，将本场当前伤兵的 A% 立即回战 | A／回战人数 |
| 追击／进攻 | 斩杀 | 敌方兵力低于阈值时，造成其当前剩余可战兵力×A% 的一次伤害；被免疫仍算已触发 | A／实际伤害 |
| 追击／守御 | 压制 | 敌方兵力低于阈值时，降低其全部伤害 A%，含普攻、反击及一次性伤害，持续至本场结束 | A／减免伤害 |
| 追击／续战 | 整队 | 敌方兵力低于阈值时，将我方本场当前伤兵的 A% 立即回战 | A／回战人数 |
| 战后／进攻 | 乘胜 | 真实交战胜利后授予下一场前 N 回合的 A% 增伤，作用伤害范围同先声 | A、N／下一场额外伤害 |
| 战后／守御 | 坚守 | 真实交战形成胜负且本方有存活部队时，授予下一场前 N 回合的 A% 减伤；撤退失败但存活同样授予 | A、N／下一场减免伤害 |
| 战后／续战 | 凯旋 | 真实交战胜利后，将本场当前伤兵的 A% 就地恢复为可战兵力；剩余伤兵照常入医院，恢复部分计入下一场开战兵力 | A／恢复人数 |

## 战报与状态提示

- **战报**
    - 双方可见本场已触发特技的名称、等级、生效回合与影响值，与契约条目并列；未触发不显示，无特技触发时不显示特技段落。
    - 伤害、回战与恢复记录实际结果；增伤记录实际额外伤害，免疫的伤害不计入增伤收益；减伤按本特技在合计减伤中的贡献份额统计，免疫时不重复记减伤。
    - 乘胜、坚守在授予场记录获得效果，在下一场记录实际影响值；接战冷却内标注“接战冷却中，开战特技未触发”。
- **地图部队信息**
    - 部队携带未消耗的乘胜、坚守时，显示效果名称与剩余连战窗口；消耗或作废后移除。单件秘宝信息仍在秘宝主界面查看。

## 获取与合成

- **获取**
    - 新秘宝与源系列通过既有 KVK 商店用征服金币（道具 100100104）兑换；秘宝沿用道具→使用入库→装备流程。
    - 通用秘宝碎片用于合成与升级，通过配置的商店、任务或奖励入口获取，橙色分解也可回收。获取方式展示当前可用来源；无可用来源时说明原因及配置的开放时间。
- **合成**
    - 消耗配置数量的碎片，选择一件已解锁的新秘宝，生成 Lv1 整件；已有同名秘宝仍可合成额外整件供其他英雄使用。
    - 未解锁项不可选并说明条件；碎片不足时跳转获取方式。确认成功后一次完成扣除与发放，刷新数量、列表和红点；状态或预览变化时不扣除，刷新后重新确认。

## 特技等级与升级

- **等级与计价**
    - 每件新秘宝独立记录等级，初始 Lv1，上限与每级升级价格由配置定义。一次只升一级，直接读取当前级升下一级的碎片价格。
    - 累计升级投入只累计实际扣除的碎片，用于分解返还，不用于决定等级。调整价格不回溯已记账投入，也不重算已有等级。
- **升级操作**
    - 弹窗展示当前与下一级效果、等级变化及碎片拥有／需要数量。确认时重新校验归属、等级、累计投入、碎片余额、装备与部队状态及消耗预览。
    - 校验通过后，扣碎片、累计投入增加与升一级一并生效，刷新该实例效果、相关秘宝战力展示与红点；失败时保持原状态并提示原因。

| 状态 | 处理 |
|---|---|
| 已满级 | 禁用升级，提示已达等级上限，不消耗碎片 |
| 碎片不足 | 保留点击，打开碎片获取方式，不提交升级、不扣资源 |
| 已分解或归属变化 | 拒绝升级，提示秘宝状态变化并刷新列表 |
| 已装备且所属部队出征中 | 拒绝升级，提示部队回城驻防后操作 |

## 背包与分解

- **入口与选择**
    - 复用现有秘宝背包及开放条件，新秘宝显示特技等级，存量显示原词条。点击分解打开一个弹窗，在其中按品质筛选、多选、预览返还并提交。
    - 已装备项不可选并提示先卸下；卸下沿用驻防限制。无选中项时分解按钮禁用，背包为空时显示“暂无秘宝”。
- **返还规则**
    - 橙色返还通用秘宝碎片＝该实例基础碎片价值＋累计实际升级投入，全额返还；无升级投入时，升级返还为 0。低于橙色只返还配置数量的破碎大陆金币。
    - 碎片合成的新秘宝以实际合成消耗记基础价值；商店或奖励取得的同配置新秘宝按取得时合成成本记账。存量橙色及源系列基础价值由配置定义，上线时一次性初始化。
    - 基础价值与累计投入随实例保留，改价不回溯；已有合法历史培养投入继续纳入返还。两种回收资源分别统计，低品质返还不使用征服金币。
- **预览与提交**
    - 同一弹窗显示选中件数、碎片与金币汇总，数量为 0 的资源不显示；橙色区分基础返还和升级返还。玩家据此确认提交，不再打开第二层确认。
    - 提交时校验整批归属、装备状态及返还预览，全部通过才一次移除实例并发放资源；任一变化则整批不处理，刷新后重新确认。
    - 取消或关闭不扣秘宝，保留有效选择；成功后刷新列表、余额及红点，并展示实际获得资源。回收与投放分开记账。

## 红点规则

| 类型 | 触发与位置 |
|---|---|
| 碎片可合成 | 足够合成任一已解锁新秘宝；显示在背包碎片项及配置的碎片货架，冒泡至秘宝入口 |
| 可升级 | 拥有未满级新秘宝且碎片足够升一级；显示在该秘宝项，冒泡至秘宝页签与英雄详情的秘宝入口 |
| 金币可购买 | 沿用商店规则：金币足够购买且商品未达限购 |
| 闲置可穿 | 沿用现有规则：有未装备的可穿秘宝时，槽位与入口显示 |

碎片增减、秘宝获得或解锁、合成、升级、分解完成时重算；条件不满足或目标不存在即消除。可分解物品本身不产生持续红点。

## 数据兼容与边界

| 场景 | 处理 |
|---|---|
| 老客户端 | 进入秘宝界面时阻止进入并引导更新；服务端照常结算已装备特技 |
| 存量与初始化 | 保留原属性及装备关系；新实例等级、投入初始为 Lv1、0，基础返还价值按分解规则记录；既有实例补记一次，重登不重复初始化 |
| 转服与跨服 | 实例、装备关系、等级、基础价值及实际投入随玩家迁移，KVK 往返不重置；未消耗授予效果的失效条件见战后规则 |
| 配置热更 | 特技参数对新建立战斗生效，进行中的战斗按开战时配置结算；升级按确认时有效价格校验预览。下调等级上限时保留已有等级，超上限实例不可继续升级 |
| 重复提交或断线重放 | 装备、卸下、合成、升级、分解返回同次操作最终结果，不重复扣除或发放 |
| 战斗无胜负结束 | 战后特技不触发；已结算伤害与恢复不回滚，局内持续效果随战斗结束失效；上一场授予效果已消耗则不退还 |
