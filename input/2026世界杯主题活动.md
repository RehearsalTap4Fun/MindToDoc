# 足球主题活动

# 1.设计目的

*   世界杯期间借赛事实热点提升活跃与付费
    
*   验证足球游戏两种操作模式
    

# 2.概述

*   虚拟球星，体验足球生涯
    
    *   签约俱乐部、训练、比赛、养成
        
*   开发足球小游戏
    
    *   使用切片模式操作单次进攻或守门
        
    *   包含划线和弹弓两种操作模式
        
    *   支持使用回溯、任意球、辅助线等局内道具
        
*   配套完整活动
    
    *   排名
        
    *   BP
        
    *   兑换商店
        
    *   竞猜

## 3.2基础关卡

*   第一关默认为引导关，未通关时重进游戏会重复触发引导
    
*   关卡结构：
    
    *   由当前关卡配置决定胜平负的条件
        
        *   通常根据关卡切片数量
            
            *   例如进球数/切片数：2/3视为胜利，1/3视为平局，0球为负
                
    *   一个关卡由多个切片组成
        
        *   切片类型
            
            *   区分进攻切片、任意球切片、点球切片、角球切片、界外球切片和守门切片
                
    *   关卡AI
        
        *   预设多套AI，可约定球员行为模式，控制难度和体验
            
*   关卡流程：
    
    *   入场展示》开球视角》切片视角，切换过度均用黑幕遮挡进入该关卡第一个切片时，停留并等待玩家操作
        
    *   每个切片可能成功或失败，无论成功失败，各自流程完成后均会进入切片回放
        
        *   成功：进入庆祝动作展示
            
        *   失败：进入回溯选择，消耗道具或者放弃回溯
            
    *   切片回放需手动点击结束，并视为完成，每完成一个切片时，自动切换到下一个切片，直到所有切片完成时，关卡视为完成
        
        *   依次弹出关卡结算和积分排名结算
            
        *   关卡结算：
            
            *   胜平负结果
                
            *   完赛奖励
                
            *   进球数奖励
                
            *   助攻数奖励
                
        *   排名结算
            
            *   与真实比赛积分规则（胜利3分，平局1分，失败0分）不同，仅按切片胜利数量算积分

*   关卡道具
    
    *   允许玩家携带道具进入关卡
        
        *   哨子：增加1次非守门切片，默认生效
            
        *   回溯：切片失败时可重新开始切片，选择使用
            
        *   瞄准：操作切片时提供辅助线预测足球轨迹，默认生效
            
    *   回溯有免费次数，携带道具时默认优先使用免费次数
        
*   不同类型的切片属性
    

| 切片类型 | 核心参数 |
| --- | --- |
| 进攻切片 | 球员初始位置/朝向、默认目的地、初始控球角色、足球位置与向量、视角、可操作夹角 |
| 任意球切片 | 罚球点位、墙体站位、可操作夹角、门将权重 |
| 点球切片 | 点球点、门将扑救方向权重、反应时间 |
| 角球切片 | 角球发球位、禁区跑位模板、第一落点权重 |
| 界外球切片 | 发球位、接应跑位、二次进攻模板 |
| 守门切片 | 对手射门方向权重、反应时间（超时失败）、判断错误失败 |

## 3.4淘汰赛

*   独立的活动页签，主题活动中后期开放
    
    *   积分赛达到第N关的玩家可参加
        
*   分组队期、匹配、比赛期
    
*   组队期
    
    *   由玩家发起组队，盟友和好友可加入队伍
        
        *   发起者可命名球队名字、队标
            
    *   需要1-N名玩家加入，组队期结束时，人数不满的位置由系统球员加入
        
*   匹配期
    
    *   根据报名队伍决定比赛轮次，最多N轮，如果报名队伍大于power(2,N)，则评分排名power(2,N)之后的球队视为报名失败，发放安慰奖励
        
*   比赛期
    
    *   由系统匹配对手，固定时间结算，允许轮空
        
    *   比赛由系统演算，根据双方球员评分影响进球和胜负，并生成模拟的比赛切片回放以及简报
        

## 3.5竞猜

*   淘汰赛的比赛开放竞猜
    
    *   仅猜胜负，赔率计算可参考X1竞猜系统
        
*   每日发放免费竞猜币，礼包也会投放竞猜币
    
*   统计竞猜命中次数和总收益做竞猜排名
    
*   开放竞猜币兑换商店可将兑换局外道具
