# 简介

## 设计目的

K1 新服大地图重构的目标，是把新开服务器从“平原自由摆方尖碑”的松散地图，调整为更具战略结构的原服地图形态。新服玩家从落地起就在方格化地图、系统堡垒、龙巢交叉点、中心王座和阶段迷雾中建立联盟扩张认知，降低后续参与 KVK 时对方格、堡垒和中心争夺规则的学习成本。

本功能**逻辑上仍是原服地图**，不是 KVK 活动。它借用 KVK 的地图骨架和部分占领认知，但保留原服玩家关系、商业化主结构、常规活动框架和 KVK 参战规则。这样做的价值是让新服早期就形成地标、路线、领地和联盟冲突，而不是等到 KVK 才第一次接触结构化地图。

## 功能简述

- **地图结构重构**：新服使用 7200x7200 方格化地图，按 24x24 的 300x300 方格组织堡垒、龙巢、圣坛、PVE 和王座区域。
- **出生分流**：从现有 9 区出生改为 4 个角落扇形出生区。扇形只用于出生分流，不代表阵营。
- **堡垒领地**：联盟领地从方尖碑覆盖区域改为已占领堡垒方格集合。联盟通过相邻堡垒逐步扩张。
- **战略点重配**：龙巢位于四格交叉点，圣坛嵌入特定堡垒方格，王座位于中心区并复用现有王座战规则。
- **迷雾进度**：原服新地图采用服务器共享迷雾，按开服进度逐层开放中间圈、中心圈和王座。
- **联盟系统适配**：新服模板下关闭方尖碑、中心堡垒、远征堡垒建造入口，保留联盟基础系统与科技主干。
- **任务活动改口径**：所有依赖旧地图结构的任务、成就、活动和排行计数，替换为堡垒、龙巢、圣坛、王座和领地方格相关目标。

## 适用范围

- **项目**：K1。
- **服务器范围**：仅新开服务器启用；老服不迁移，不做旧地图转新地图。
- **客户端范围**：需要支持新服地图模板的客户端版本；旧客户端进入新服时必须按版本策略降级或拦截。
- **参考玩法**：借用 K1 现有 KVK 地图骨架、堡垒认知、龙巢战斗流程与王座战规则，但不引入 KVK 阵营、跨服匹配、天气、女神等完整 KVK 活动机制。

| 迷雾开放 | 服务器共享迷雾，按开服时间分层开放 | 不做个人付费解锁；KVK 期间原服迷雾时钟不暂停 |
| 联盟建造 | 新服模板下关闭方尖碑、中心堡垒、远征堡垒建造入口 | 联盟基础系统、联盟科技主干、联盟礼物、联盟商店等保持 |
| 商业化 | 商业化主结构不重构 | 迁城、保护罩、加速、联盟权益和与旧地图目标绑定的礼包描述需逐项校验 |
| 兼容策略 | 新服模板隔离 + 旧客户端降级/拦截 + 线上数据回归 | 大地图 battle、跨场景逻辑、新对象、任务成就类型、实体数据、多语言参数均属于高兼容风险 |

# 详细规则

## 全局玩法机制

- **核心循环**：玩家进入新服后选择或被分配到 4 个扇形出生区之一；加入联盟后，以初始共享堡垒周边为起点攻占普通堡垒；联盟通过相邻堡垒扩张领地，争夺龙巢、圣坛、中心圈和王座；迷雾按开服进度逐层打开，推动新服从出生区扩张到中间圈、中心圈和首次王座战。
- **复用原则**：能复用原服或 KVK 现有规则的部分不重写机制，只调整地图目标、入口、坐标、开放时间和配置口径。
- **配置原则**：地图坐标、堡垒类型、迷雾层级、PVE 强度、开放时间、占领时长倍率、首战免战时长、科技上限和任务计数均由配置表定义，字段见 [K1新服大地图重构-配置表结构.md](K1新服大地图重构-配置表结构.md)。
- **不可引入方向**：{{red:不得把新服原服地图做成完整 KVK 活动}}，不得引入跨服阵营、KVK 匹配、KVK 天气和 KVK 女神等活动专属机制。

## 地图结构

### 基本参数

| 项 | 规则 |
|----|------|
| 地图尺寸 | 7200x7200，与现有大地图/KVK 地图一致。 |
| 方格大小 | 300x300，形成 24x24 方格基础。 |
| 总方格数 | 理论 576 格；需扣除中心王座区、边界不可用区和特殊地形，实际可用堡垒方格数由配置表定义。 |
| 区域构成 | 堡垒方格、龙巢交叉点、火龙巢交叉点、王座方格、圣坛附属点、PVE 刷新点。 |

### 分区规则

| 分区 | 位置 | 规则 |
|------|------|------|
| 扇形出生区 | 4 个角落 | 玩家出生落城区，PVE 强度最低，含初始共享堡垒。扇形仅作出生分流，不代表阵营。 |
| 中间圈 | 出生区与中心之间 | 第一层迷雾覆盖，中级 PVE，分布部分龙巢、火龙巢、圣坛和恶魔守卫。 |
| 中心圈 | 地图中心外圈 | 第二层迷雾覆盖，高级 PVE，分布高级龙巢、火龙巢、圣坛和通向王座的堡垒。 |
| 王座方格 | 地图正中心 | 独立配置，复用 K1 现有王座战规则。 |

### 堡垒方格属性

- **方格 ID**：唯一标识地图方格。
- **归属联盟**：0 表示中立或共享；非 0 表示占领联盟。
- **堡垒类型**：初始共享堡垒、普通堡垒、中心圈堡垒、王座关联堡垒等，由配置表定义。
- **附属圣坛**：0 或 1 个，若存在则配置圣坛类型。
- **相邻战略点**：可关联 0-N 个龙巢、火龙巢或其他四格交叉点战略点。
- **PVE 强度档位**：按分区配置，用于野怪、泰坦、火龙巢和恶魔守卫强度。
- **迷雾层级**：0 为常开，1 为第一层迷雾，2 为第二层迷雾。
- **相邻方格**：用于判定可攻击列表和领地连通，具体拓扑由配置表定义。
- **免战截止时间**：运行时状态。当前仅由新联盟首战成功写入，未来可扩展给其他机制。

## 出生分配

### 出生区数量

- 新服从 9 区出生改为 **4 个扇形出生区**。
- 4 个扇形区共享同一服务器身份，玩家之间没有阵营敌对关系。
- 联盟成员可以分布在任意扇形区，联盟迁城也可以跨扇形，只要满足联盟领地和迁城规则。

### 出生分配算法

- **开服自由选择期**：开服前若干天内，新玩家可在 4 个扇形出生区中自由选择落城点；天数由配置表定义，推荐初始值为 7 天。
- **自由选择期结束后**：新玩家由系统自动分配到当前人数最少的扇形区，避免头部联盟或同语言玩家过度集中。
- **容量保护**：若某扇形区落城密度接近配置上限，系统不再把新玩家自动分配到该扇形区。

### 新玩家保护

- 新玩家出生后享受现有新手保护罩规则。
- 若新玩家落入已被联盟占领的方格，保护罩内不可被攻击。
- 保护罩失效前，系统应引导玩家迁移到无归属方格或己方联盟领地方格；保护罩失效后的攻击与迁城限制按原服规则执行。

## 堡垒占领规则

### 相邻扩张

- **核心规则**：一个联盟可攻击的堡垒 = 该联盟已占领堡垒的相邻普通堡垒 + 初始共享堡垒第一圈的可攻击普通堡垒。
- 联盟成立时若没有任何堡垒，首个可攻击目标来自任一初始共享堡垒相邻第一圈。
- 占领任意堡垒后，该堡垒相邻的所有非免战普通堡垒进入可攻击列表。
- 扩张不允许跳跃；没有相邻关系的堡垒不可攻击。
- 若目标处于免战状态，即使满足相邻或首战条件，也不可攻击。

### 攻击资格

- 只有满足相邻条件或零堡垒首战条件的联盟可以发起攻击。
- 攻击行为复用现有联盟建筑攻击的派兵、集结、行军和战斗表现规则；若堡垒战需要专属表现，仅作为表现层适配，不改变资格判定。
- 攻击成功后堡垒归属变更为攻击方联盟，原占领方失去该方格。
- 攻击失败后堡垒归属不变；进攻方消耗、伤兵、战报和行军返回按现有战斗规则处理。

### 归属规则

- **堡垒归联盟不归个人**：占领贡献者退盟、转服或离线不影响堡垒归属。
- **联盟解散**：所属堡垒进入解散待处理状态，24 小时后自动变为中立，可被任一满足相邻条件的联盟攻击。24 小时内若项目已有联盟恢复机制，则按现有机制处理。
- **归属不衰减**：堡垒占领后永久归属该联盟，除非被打下、联盟解散或配置明确重置。
- **王座例外**：王座方格不按普通堡垒归属规则处理，优先遵循现有王座战重置规则。

### 联盟领地判定

- **联盟领地 = 该联盟已占领堡垒方格集合**。
- 领地保护科技的触发条件从“城堡位于方尖碑覆盖区域”改为“城堡所在方格属于自己联盟”。
- 联盟迁城落点必须位于联盟领地方格内，并继续满足现有盟主城堡距离限制。
- 联盟迁城不是新联盟首战的前置条件；零堡垒联盟可以直接按照初始共享堡垒第一圈规则发起首战。

### 新联盟首战规则

- 玩家侧不展示“冷启动”概念。联盟若当前堡垒占领数为 0，地图只显示初始共享堡垒相邻第一圈中可攻打的普通堡垒。
- 首战目标可以是中立堡垒，也可以是已被其他联盟占领但免战已结束的普通堡垒。
- 首战目标不可以是免战中的堡垒。
- 首战成功后，该联盟后续按普通相邻扩张规则行动。
- 首次占领成功的堡垒进入免战时间；免战时长由配置表定义，推荐初始范围 12-24 小时。
- 免战只保护该堡垒，不保护该联盟的其他堡垒。
- 同一玩家、同一盟主或关键成员在短期内反复解散重建联盟以获取首战免战的行为，需要记录联盟解散、创建、盟主变更和关键成员迁移日志；是否限制重复触发由配置表定义。

### KVK 期间的原服堡垒

- 玩家参战 KVK 期间，原服堡垒、联盟领地、龙巢、圣坛和王座归属数据完整保留。
- 玩家可按现有规则随时从 KVK 战场返回原服。
- 原服普通堡垒在 KVK 期间不冻结，仍可被满足资格的联盟攻击。
- KVK 开启期内，原服普通堡垒占领所需时间按固定倍率延长；倍率由配置表定义，推荐初始范围 2-3 倍。
- 王座方格不适用普通堡垒占领时间延长，仍以王座战规则为准。

## 龙巢、火龙巢与圣坛

### 龙巢

- 龙巢位于 4 个相邻堡垒的交叉区域，不属于任何单个堡垒方格内部。
- 龙巢作为独立战略点显示在四格交界处，攻击入口由相邻堡垒提供。
- 占领任一相邻堡垒的联盟，可对该龙巢发起攻击。
- 龙巢占领是独立战斗行为，不随堡垒自动归属。
- 同一龙巢最多有 4 个方向的相邻堡垒可提供攻击资格。
- 归属联盟失去全部相邻堡垒时，龙巢进入失效状态；失效状态下保留原归属但加成暂停。
- 任一联盟占有相邻堡垒后即可发起争夺；原归属联盟重新获得任一相邻堡垒且龙巢未被其他联盟打下时，龙巢恢复生效。
- 龙巢占领数量上限由联盟科技新分支决定，满级上限复用现有 8 个口径。
- 龙巢加成规则复用现有龙巢加成，不在本功能中重做数值体系。

### 火龙巢

- 火龙巢使用与龙巢一致的交叉点攻击资格：占领任一相邻堡垒的联盟可发起攻击。
- 火龙巢等级从 KVK 高等级段下调为适配新服的 1-6 级梯度，具体等级和分布由配置表定义。
- 火龙巢分布在出生区、中间圈和中心圈，数量按地图配表控制。
- 火龙巢战斗流程和奖励结构优先复用现有规则；若需要新增奖励档位，仅在配置表中扩展。

### 圣坛

- 圣坛嵌入到特定堡垒方格内，位置固定，由配置表决定。
- 圣坛类型保留 5 种：智慧泉、远古矿坑、金矿场、英灵殿、工具屋。
- 占领带圣坛的堡垒方格后，联盟自动获得该圣坛加成。
- 圣坛不作为独立占领目标，不额外发起圣坛战斗。
- 圣坛加成规则复用现有规则；本功能只调整圣坛归属来源。

## 王座方格

- 王座位于地图正中心，迷雾层级为 2，需中心圈开放后才可见和进入。
- 首次本服王座推荐在开服 D21 开放，具体时间由配置表定义。
- 王座战的战斗、占领、重置、奖励、积分和 buff 完全复用 K1 现有王座战/跨服王座战规则。
- 若新地图需要不同入口、开放时间、坐标或提示，仅新增适配配置，不修改王座战核心逻辑。
- 王座归属方为联盟。
- 王座周边中心圈需要配置足够公共通路和中立锚点，避免单一联盟在王座开放前完全封锁接近路径。

## 迷雾系统

### 迷雾规则

- 新服地图迷雾为**服务器共享状态**，不是玩家个人探索视野。
- 任何个人付费、礼包或道具不得提前解锁迷雾。
- 项目已有迷雾系统可复用时，本功能只新增区域划分、开放时间和地图表现配置。

### 迷雾层级

| 层级 | 区域 | 开放规则 | 表现 |
|------|------|----------|------|
| 0 | 4 个扇形出生区、初始共享堡垒 | 开服即可开放 | 方格、归属、PVE、战略点按正常状态展示 |
| 1 | 中间圈 | 推荐开服 D8 开放，由配置表定义 | 开放前可见轮廓和 icon，但隐藏归属与类型信息 |
| 2 | 中心圈、王座周边 | 推荐开服 D15 开放，由配置表定义 | 开放后可迁入、行军和攻击符合资格的目标 |
| 王座开放 | 王座方格 | 推荐开服 D21 开放，由配置表定义 | 王座可被攻击/占领，按王座战规则运行 |

### 迷雾状态下的表现

- 方格和堡垒 icon 可见，但归属信息隐藏。
- 龙巢、火龙巢、圣坛 icon 可见，但类型、等级和归属信息隐藏。
- 部队和城堡不可进入迷雾覆盖的方格。
- 迷雾开放后，该区域按正常地图规则展示，城堡可迁入，部队可行军。

### KVK 期间的迷雾

- 原服迷雾开放时钟基于服务器创建时间累计，KVK 期间不暂停。
- 玩家在 KVK 战场期间，原服迷雾仍按时开放。
- 玩家 KVK 归来后发现原服已有新区域开放，视为正常服务器进度。

## PVE 强度分布

| 分区 | 野怪等级 | 火龙巢等级 | 恶魔守卫 |
|------|----------|------------|----------|
| 扇形出生区 | 1-3 级 | 1-3 级 | 不刷新 |
| 中间圈 | 3-5 级 | 3-5 级 | 部分坐标刷新 |
| 中心圈 | 5-6 级 | 5-6 级 | 大部分坐标刷新 |
| 王座方格 | 特殊配置 | 不刷新 | 王座守卫，复用王座战规则 |

- 野怪与泰坦刷新逻辑复用现有原服规则，等级按地图分区配置。
- 集结、自动集结、宝箱奖励和战斗结算规则保持不变。
- 恶魔守卫作为与 KVK 中立 NPC 同类的野生 PVE，刷新在中间圈和中心圈，所有玩家均可攻击。
- 恶魔守卫按周期刷新，击败后经配置周期在原坐标重新出现，推荐初始范围 7-14 天。
- 龙巢守卫属于龙巢内部战斗数据，不显示为地图中立 NPC，不影响堡垒攻击资格。

## 联盟科技与联盟系统适配

### 联盟科技新增分支

- **堡垒占领数上限**：控制联盟可同时占领的普通堡垒数量。初始值、每级增量和满级上限由配置表定义；推荐初始值 2 个，满级按新地图总方格数和期望头部联盟规模配置在 30-60。
- **龙巢占领数上限**：控制联盟可同时占领的龙巢数量。初始值由配置表定义，满级上限复用现有 8 个。
- 新分支独立于现有科技分支，不影响捐献规则、宝石捐献、无限科技等主干规则。

### 保留不变

- 联盟报名、退出、弹劾、盟主竞选、AI 联盟规则。
- 联盟公告、投票、聊天、官员群聊。
- 联盟官职、联盟阶级自定义、联盟机器人接管。
- 联盟礼物、联盟商店、联盟成就、联盟挑战。
- 联盟自动踢人、联盟转服、联盟冷冻期、联盟帮助。
- KVK 联盟礼物分配。

### 调整项

- 新服模板下，联盟建造板块关闭方尖碑、中心堡垒、远征堡垒入口。
- 联盟建造或战略指令保留堡垒占领、龙巢占领、火龙巢占领相关入口。
- 联盟领地判定改为已占领堡垒方格集合。
- 联盟迁城落点改为联盟领地方格内，同时保留盟主城堡距离限制。
- 领地保护科技触发条件改为城堡所在方格属于自己联盟。

### 删除项

- 方尖碑系统在新服模板下完全不启用，不出现在联盟建造和地图 UI 中。
- 中心堡垒、远征堡垒在新服模板下不启用。

## KVK 兼容

- KVK 玩法本身完全不变。
- 玩家/联盟报名 KVK 的条件、流程和入口保持现有规则。
- 报名后玩家可选择进入 KVK 战场，进入后在 KVK 战场作战，规则不变。
- 玩家可按现有规则随时返回原服。
- KVK 期间原服堡垒、联盟领地、龙巢、圣坛和王座归属数据完整保留。
- KVK 结束后玩家回归原服，原服地图状态不因 KVK 结束而重置。
- 原服普通堡垒在 KVK 期间的占领时间倍率延长属于新服地图的保护性适配，不能影响 KVK 战场内堡垒规则。

## 活动、任务、成就与排行适配

### 总原则

商业化主结构、原服常规活动框架、PVE/PVP 基础战斗规则尽量保留。所有依赖旧地图结构的活动、任务、成就和排行计数必须重新定义，尤其是方尖碑、中心堡垒、远征堡垒、龙巢连接和联盟领地面积相关目标。

### 旧计数到新计数

| 旧目标/旧计数 | 新目标/新计数 |
|----------------|----------------|
| 建造方尖碑 | 占领普通堡垒 |
| 修建/升级联盟中心堡垒 | 占领堡垒总数 / 联盟领地方格数 |
| 修建/升级远征堡垒 | 占领中间圈或中心圈堡垒 |
| 连接龙巢 | 占领龙巢相邻堡垒 / 攻击并占领龙巢 |
| 占领龙巢 | 占领交叉点龙巢 |
| 占领圣坛 | 占领带圣坛的堡垒方格 |
| 王座相关目标 | 占领都城/王座、参与王座战、获得王座积分 |
| 联盟领地面积 | 联盟占领堡垒方格数 |
| 联盟建筑战斗 | 堡垒战 / 龙巢战 / 火龙巢战 / 王座战 |

### 任务与成就

- 主线任务删除或替换“建造方尖碑”“连接龙巢”“建造联盟堡垒”类目标。
- 联盟任务新增或替换为“首次占领堡垒”“占领 N 个堡垒”“参与堡垒战”“占领龙巢”“占领带圣坛堡垒”“进入中间圈/中心圈”等目标。
- 成就按堡垒、龙巢、王座、圣坛和领地方格数重新配置。
- 新手联盟引导必须解释“初始共享堡垒 -> 相邻堡垒 -> 龙巢交叉点 -> 中心圈/王座”的路径。
- 任务/成就类型和数值属于高兼容风险项，必须隔离新服任务链和旧服任务链。

### 活动与排行

- 最强领主、联盟排行类活动若包含联盟建筑、方尖碑、龙巢连接计数，需要映射为堡垒、龙巢、王座相关计数。
- 王座战活动只适配地图入口、开放时间和都城/王座位置，不改战斗和奖励核心。
- 联盟活动中涉及联盟领地、联盟建设、联盟建筑战斗的任务需要重配。
- PVE 活动中野怪、泰坦、采集等基础计数保持不变；若要求特定区域进入或怪物等级，需要结合迷雾层级调整。
- 排行口径新增或替换为联盟占领堡垒数、龙巢数、都城/王座积分、领地方格数等指标。

## 商业化适配

- 商业化模型不重构。
- 迁城、保护罩、加速、赛季卡、联盟相关权益需要校验是否受新领地定义影响。
- 若礼包、权益或文案与方尖碑、联盟建筑、龙巢连接直接绑定，需要改描述或替换生效条件。
- 任何付费权益不得提前解锁服务器共享迷雾。
- 与占领时长、免战时长、PVE 刷新、王座开放相关的商业化加速或道具，必须先确认是否会破坏新服地图节奏。

## 红点规则

| 触发场景 | 展示位置 | 消除条件 | 刷新时机 |
|----------|----------|----------|----------|
| 新区域迷雾开放 | 大地图入口、地图内区域提示 | 玩家进入地图并查看开放区域后消除 | 开服天数到达、重新登录、服务器推送 |
| 联盟出现可攻击堡垒 | 联盟战略入口、大地图目标提示 | 玩家打开可攻击目标列表或联盟发起攻击后消除 | 联盟占领变化、免战结束、迷雾开放 |
| 堡垒/龙巢/火龙巢战斗可参与 | 联盟入口、地图战略点 | 战斗结束、玩家查看战斗详情或资格失效后消除 | 目标进入可攻击状态、战斗开启、资格变化 |
| 新联盟首战可进行 | 联盟入口、地图初始共享堡垒周边提示 | 联盟占领首个堡垒或玩家查看首战引导后消除 | 加入联盟、联盟堡垒数变为 0、免战状态变化 |
| 王座首次开放 | 大地图中心区、王座入口 | 玩家查看王座详情后消除 | 开服达到王座开放时间、重新登录 |

红点的上级入口冒泡、角标样式和优先级遵循 K1 统一红点规范；若规范未覆盖地图战略点，需要由 UI/客户端补充表现方案。

## 边界情况处理

| 场景 | 处理 |
|------|------|
| 零堡垒联盟查看地图 | 只高亮初始共享堡垒第一圈中非免战、可攻击的普通堡垒；不展示“冷启动”内部概念。 |
| 首战目标进入免战 | 免战优先级最高，目标从可攻击列表移除。 |
| 首战成功后继续进攻 | 联盟立即切换为普通相邻扩张规则；首战免战只保护首个堡垒。 |
| 免战期间主动进攻 | 是否提前解除免战由配置决定；未配置前默认不解除，但必须在配置表中明确。 |
| 联盟解散 | 联盟堡垒进入 24 小时待处理状态，期满变为中立；龙巢、圣坛等依赖堡垒归属的加成按失效或中立规则处理。 |
| 玩家退盟 | 玩家个人不带走堡垒、龙巢或圣坛归属；若城堡不在新联盟领地内，迁城与保护按现有规则处理。 |
| 盟主转让 | 不影响联盟堡垒归属；防滥用日志记录盟主变更。 |
| 龙巢失去全部相邻堡垒 | 龙巢进入失效状态，保留原归属但暂停加成；重新拥有相邻堡垒且未被打下时恢复。 |
| 圣坛所在堡垒被攻占 | 圣坛加成随堡垒归属即时转移到新占领联盟。 |
| 迷雾区内配置战略点 | 迷雾开放前可展示轮廓或 icon，但隐藏类型、等级、归属和可交互入口。 |
| 迷雾开放时玩家在 KVK | 原服迷雾照常开放；玩家返回原服后看到新区域开放。 |
| KVK 期间原服堡垒被攻击 | 按原服新地图规则处理；普通堡垒占领时间使用 KVK 期间倍率。 |
| 王座开放前中心圈被封锁 | 通过中心圈方格数量、公共通路和中立锚点配置缓解；王座战本身不新增破封规则。 |
| 旧任务下发到新服 | 不允许。新服模板必须使用新任务链；若异常下发，客户端应隐藏无法完成目标并上报。 |
| 旧客户端遇到新对象 | 不得崩溃；按版本策略强更、隐藏、默认模型或默认图标兜底。 |
| 重复占领结算请求 | 服务器以最终战斗结果和目标当前归属为准，重复请求不得重复发奖励或重复变更归属。 |
| 配表热更修改相邻关系 | 已存在归属和进行中战斗优先保持；相邻关系热更须有停服或维护窗口，不允许在战斗中静默改变资格。 |

## 风险与缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| 王座 buff 长期集中 | 头部联盟可能持续压制其他联盟 | 不额外加强王座 buff；中心圈配置足够通路和方格，避免完全封锁。 |
| D8 前地图感受偏小 | 新服早期玩家可能觉得可争夺目标不足 | 初始共享堡垒数量和出生区 PVE 密度需按同服联盟数配置；灰度观察后调整 D8/D15/D21。 |
| 首战免战被滥用 | 小号联盟或重建联盟反复拿免战骚扰 | 限定首战范围、记录重建日志、通过配置限制短期重复触发。 |
| 既有联盟被零堡垒联盟攻击感到不公平 | 公共首战圈争议 | 仅允许初始共享堡垒第一圈、非免战目标；被攻击方给出清晰战报和反攻信息。 |
| UI 信息密度过高 | 方格归属、战略点、迷雾、PVE、免战堆叠 | 地图采用分层显示；缩略视图只显示归属颜色和关键图标，详情弹窗显示完整信息。 |
| 首个 KVK 周期兼容风险 | 原服新地图与 KVK 往返流程互相影响 | 灰度期至少覆盖一个完整 KVK 周期，重点验证堡垒时间倍率、迷雾开放和归属保留。 |
| 旧活动任务不可完成 | 玩家卡任务、活动积分异常 | 上线前输出旧计数到新计数替换表，覆盖主线、联盟任务、成就、排行和客服 FAQ。 |
| 新旧版本兼容 | 旧客户端崩溃或展示错乱 | 按高兼容风险清单处理新对象、battle、任务成就、多语言参数和实体字段。 |
