# 2026世界杯主题活动美术需求

**整理日期**：2026-06-02
**来源文档**：`output/2026世界杯主题活动-开发文档.md`
**适用范围**：移动端 iOS / Android，竖屏单手操作，主游戏内限时活动。

## 1. 美术目标

本活动需要在世界杯期间快速建立“足球主题 + 球星生涯 + 轻操作小游戏”的识别度。美术应服务三个目标：

- **主题辨识**：第一屏能明确感知世界杯/足球/俱乐部赛事氛围。
- **操作清晰**：切片玩法中的球、球员、门将、轨迹、落点和道具状态必须清楚，不能被装饰干扰。
- **活动商业化**：BP、礼包、兑换商店、排名奖励需要有足够吸引力，但整体仍保持活动页签的高可读性。

建议风格为“明亮竞技体育 + 活动庆典包装”，避免过暗、过写实或过复杂的球场画面影响移动端操作判断。

## 2. 视觉基调

### 2.1 主题关键词

- 足球
- 世界杯
- 球星成长
- 俱乐部签约
- 联赛积分
- 淘汰赛
- 竞猜
- 排名奖励

### 2.2 色彩方向

- 主色建议：草坪绿、冠军金、深色看台/夜赛背景。
- 辅色建议：白色球衣、红/蓝队伍识别色、警示橙、成功绿。
- UI 注意：活动界面不要被单一绿色铺满；球场区域可用绿色，功能面板建议用深色或中性色承载信息。

### 2.3 画面层级

- 一级视觉：球星角色、球场、赛事奖杯/冠军符号。
- 二级视觉：球队徽章、国旗/地区、合同、排名奖杯、BP 奖励。
- 三级视觉：金币、门票、竞猜币、局内道具、局外道具、外观券。

## 4. P0 首批交付建议

为支持玩法和主流程开发，首批建议只做能覆盖核心链路的资产：

1. 4 个角色立绘/头像。
2. 国籍图标与基础球队徽章模板。
3. 竖屏球场背景、球门、足球、球员/门将 token。
4. 轨迹辅助线、落点、可操作夹角、反应时间条。
5. 哨子、回溯、瞄准 3 个局内道具图标。
6. 金币、门票、竞猜币 3 个货币图标。
7. 创角、切片操作、关卡结算、养成、积分赛 5 个核心页面 UI 皮肤。
8. 进球成功、失败、回溯重置 3 类基础反馈动效。

## 5. P1 扩展交付建议

在核心玩法稳定后，再补活动商业化与社交竞争资产：

1. 签约亮相动画与合同卡美术。
2. 淘汰赛队标编辑素材与对阵卡包装。
3. 竞猜、排名、BP、商店、礼包页面完整 UI 皮肤。
4. 外观奖励、局外道具、外观券图标模板。
5. 排名前三、冠军、晋级、淘汰、赛后简报视觉包装。

## 6. P2 可后置资产

以下资产对初期开发阻塞较低，可后置：

1. 完整开场视频。
2. 多套球场皮肤。
3. 多套球队徽章细分风格。
4. 高级角色庆祝动作。
5. 稀有外观展示动画。
6. 大型活动宣传图和运营 Banner。

## 7. 待策划确认项

这些问题会影响美术数量和规格，需要策划/产品尽快确认：

- 国籍/地区最终列表。
- 球队数量、球队星级上限、是否使用真实国家/俱乐部影射。
- 4 个角色的性别、年龄、体型、球衣风格和角色定位。
- 球衣是否需要可换肤，外观奖励是否落在球衣、鞋、发型、头像框或庆祝动作上。
- 局外道具具体类型和数量。
- BP、排名、淘汰赛奖励的稀有度分级。
- 礼包和商店商品是否需要独立大图，还是只用图标。
- 是否需要适配多语言导致 UI 文本区域扩展。
- 是否存在 FIFA/世界杯官方授权限制，若无授权需避免直接使用真实标识、真实球队队徽和官方赛事 Logo。

## 8. 交付格式建议

### 8.1 图片资产

- UI 图标：PNG/WebP，透明背景，提供 1x/2x/3x 或按项目规范切图。
- 角色立绘：透明背景 PNG/WebP，需提供全身/半身/头像裁切。
- 球场背景：竖屏安全区版本，需标注 HUD、操作区、底部栏遮挡范围。
- 队徽/国籍图标：建议使用可缩放源文件，导出游戏所需尺寸。

### 8.2 动效资产

- UI 动效：优先 Lottie / 序列帧，按引擎支持确认。
- 比赛反馈：可先用轻量粒子、文字动效和镜头缩放实现。
- 开场视频：如制作成本高，MVP 可先交静态背景 + UI 过场。
