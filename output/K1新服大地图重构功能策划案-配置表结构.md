# K1新服大地图重构功能策划案 · 配置表结构（数值策划填表）

> **定位**：本文只描述数值、地图、活动策划在 Excel 中需要维护的配置结构。
> **规则依据**：主策划案 [K1新服大地图重构功能策划案.md](K1新服大地图重构功能策划案.md)。
> **列级 SSOT**：如项目已有正式 Excel，以正式表头为准；本文用于对齐应有哪些配置页签与字段含义。

# 配置表概览

## 配置文件清单

| 文件 | 说明 | 策划维护 |
|------|------|----------|
| `new_server_map.xlsx` | 新服大地图结构、对象、迷雾、出生、占领总配置 | 玩法/地图/数值 |
| `alliance_tech.xlsx` | 联盟科技新增分支或既有分支扩展 | 数值 |

## 公共 / 外部依赖

| 类型 | 典型表 / 机制 | 本功能用法 | 策划动作 |
|------|----------------|------------|----------|
| 联盟科技 | 既有联盟科技表 | 新增堡垒占领数上限、龙巢占领数上限分支 | 确认分支位置、等级、消耗、上限 |
| 王座战 | 既有王座战配置 | 复用战斗、重置、奖励与 buff | 仅补新地图入口、开放时间、坐标引用 |
| 龙巢 | 既有龙巢战斗与加成 | 复用战斗流程、守卫与加成 | 补交叉点坐标、相邻堡垒、等级梯度 |
| 圣坛 | 既有圣坛类型与加成 | 复用加成规则 | 补圣坛所在堡垒和类型 |
| kvk堡垒 | 既有 KVK 堡垒攻占规则 | 复用攻击与占领规则 | 无需额外配置，直接复用 |
| 任务/活动 | 既有主线、联盟任务、成就、排行配置 | 替换旧地图目标 | 直接修改对应任务和活动配置，不新增独立映射表 |
| 多语言 | K1 项目多语言规范 | 新增入口、提示、状态文案 | 按项目规范命名并查重 |

## 专用表一览

| 页签 | 用途 | 主要关联 | 填表 |
|------|------|----------|------|
| `MapBasic` | 地图基础参数 | 全局 | 地图策划 |
| `MapRegion` | 分区与迷雾层级 | `MapBasic`、`FogLayer` | 地图策划 |
| `FortressGrid` | 堡垒方格配置 | `MapRegion`、`AltarPoint`、`DragonNestPoint` | 地图策划 |
| `InitialSharedFortress` | 初始共享堡垒配置 | `FortressGrid` | 地图策划 |
| `FortressAdjacency` | 堡垒相邻关系 | `FortressGrid` | 地图策划/程序校验 |
| `DragonNestPoint` | 龙巢点位配置 | `FortressGrid`、既有龙巢配置 | 玩法/地图 |
| `AltarPoint` | 圣坛点位配置 | `FortressGrid`、既有圣坛配置 | 玩法/地图 |
| `ThronePoint` | 王座入口与开放配置 | 既有王座战配置、`FogLayer` | 玩法 |
| `FogLayer` | 迷雾层级与开放时间 | `MapRegion` | 玩法 |
| `SpawnRegion` | 出生区与分配规则 | `MapRegion` | 玩法 |
| `FortressOccupyRule` | 堡垒占领、免战、KVK 倍率 | `FortressGrid` | 玩法/数值 |
| `AllianceTechBranch` | 联盟科技新分支 | 既有联盟科技表 | 数值 |

# 地图基础配置

## `MapBasic`

| 字段 | 类型 | 说明 | 填表要点 |
|------|------|------|----------|
| `map_id` | int/string | 新服大地图模板 ID | 与旧服地图模板区分 |
| `map_name` | string | 地图模板名称 | 仅策划识别或后台展示 |
| `width` | int | 地图宽度 | 初始 7200 |
| `height` | int | 地图高度 | 初始 7200 |
| `grid_size` | int | 单格尺寸 | 结合 24x24 基础格子结构确定 |
| `grid_count_x` | int | 横向方格数 | 初始 24 |
| `grid_count_y` | int | 纵向方格数 | 初始 24 |
| `enabled_server_type` | enum | 启用服务器类型 | 仅新服模板启用 |
| `min_client_version` | string | 最低客户端版本 | 低于该版本的客户端不得进入新地图 |

## `MapRegion`

| 字段 | 类型 | 说明 | 填表要点 |
|------|------|------|----------|
| `region_id` | int/string | 分区 ID | 出生区、中间圈、核心圈、王座区等 |
| `region_type` | enum | 分区类型 | `spawn` / `middle` / `center` / `throne` |
| `region_name` | string | 分区名称 | 后台识别；展示文案走多语言 |
| `fog_layer` | int | 对应迷雾层级 | 0/1/2/3 |
| `grid_range` | string | 分区覆盖格子或多边形范围 | 可按项目地图工具格式填写 |
| `is_birth_available` | bool | 是否允许出生落城 | 仅出生区为是 |

# 堡垒配置

## `FortressGrid`

| 字段 | 类型 | 说明 | 填表要点 |
|------|------|------|----------|
| `grid_id` | int/string | 堡垒方格唯一 ID | 全地图唯一 |
| `map_id` | int/string | 所属地图模板 | 关联 `MapBasic` |
| `grid_x` | int | 方格横向序号 | 与地图工具一致 |
| `grid_y` | int | 方格纵向序号 | 与地图工具一致 |
| `center_pos` | string | 方格中心坐标 | 用于展示和寻路 |
| `region_id` | int/string | 所属分区 | 关联 `MapRegion` |
| `fortress_type` | enum | 堡垒类型 | 初始、普通、王座关联等 |
| `fortress_level` | int | 堡垒等级 | 按圈层和既有堡垒等级体系配置 |
| `is_occupiable` | bool | 是否可被联盟占领 | 初始堡垒为否 |
| `is_initial` | bool | 是否初始堡垒 | 首战锚点 |
| `altar_id` | int/string | 附属圣坛 ID | 无则为空 |
| `fog_layer` | int | 迷雾层级 | 可继承分区或单独覆盖 |
| `display_priority` | int | 地图展示优先级 | 用于重叠图标处理 |

## `InitialSharedFortress`

| 字段 | 类型 | 说明 | 填表要点 |
|------|------|------|----------|
| `shared_id` | int/string | 初始堡垒配置 ID | 全表唯一 |
| `grid_id` | int/string | 对应堡垒方格 | 必须是不可占领的初始堡垒 |
| `spawn_region_id` | int/string | 所属出生区 | 保证每个出生区都有足够锚点 |
| `enabled` | bool | 是否启用 | 便于灰度调整 |

## `FortressAdjacency`

> 相邻拓扑固定采用四邻。本页签只允许维护上、下、左、右关系，不允许把对角或其他非四邻方格配置为可攻击相邻方格；阻挡区可通过关闭对应四邻通路处理。

| 字段 | 类型 | 说明 | 填表要点 |
|------|------|------|----------|
| `grid_id` | int/string | 当前堡垒方格 ID | 关联 `FortressGrid` |
| `adjacent_grid_id` | int/string | 相邻堡垒方格 ID | 互邻关系需校验 |
| `direction` | enum | 相邻方向 | 仅 `up` / `down` / `left` / `right` |
| `is_attack_path` | bool | 是否提供攻击资格 | 阻挡区或不可通行边界可关闭 |

# 地图对象配置

## `DragonNestPoint`

> 龙巢复用既有对象类型、显示、战斗和占领规则。本页签只维护新地图模板中的龙巢实体配置、交叉点坐标及四邻堡垒引用，不代表新增地图对象类型。

| 字段 | 类型 | 说明 | 填表要点 |
|------|------|------|----------|
| `dragon_nest_id` | int/string | 龙巢 ID | 全地图唯一 |
| `map_id` | int/string | 所属地图模板 | 关联 `MapBasic` |
| `pos` | string | 地图坐标 | 位于多个堡垒交叉区域 |
| `region_id` | int/string | 所属分区 | 中间圈或中心圈为主 |
| `fog_layer` | int | 迷雾层级 | 未开放前隐藏详情 |
| `adjacent_grid_ids` | string/list | 可提供攻击资格的堡垒 | 通常最多 4 个 |
| `dragon_type` | enum/int | 龙巢类型 | 复用既有龙巢配置 |
| `dragon_level` | int | 龙巢等级 | 按圈层配置等级梯度 |
| `guard_group_id` | int/string | 守卫配置组 | 复用既有龙巢战斗流程 |
| `buff_group_id` | int/string | 加成配置组 | 复用既有龙巢加成 |
| `max_occupy_limit_group` | int/string | 占领上限组 | 关联联盟科技 |

## `AltarPoint`

| 字段 | 类型 | 说明 | 填表要点 |
|------|------|------|----------|
| `altar_id` | int/string | 圣坛 ID | 全地图唯一 |
| `map_id` | int/string | 所属地图模板 | 关联 `MapBasic` |
| `grid_id` | int/string | 所在堡垒方格 | 占领该堡垒即获得圣坛 |
| `altar_type` | enum/int | 圣坛类型 | 复用既有圣坛类型 |
| `buff_group_id` | int/string | 加成配置组 | 复用既有圣坛加成 |
| `display_pos` | string | 地图展示坐标 | 通常在堡垒方格内 |
| `enabled` | bool | 是否启用 | 便于灰度调整 |

## `ThronePoint`

| 字段 | 类型 | 说明 | 填表要点 |
|------|------|------|----------|
| `throne_id` | int/string | 王座配置 ID | 新服地图唯一 |
| `map_id` | int/string | 所属地图模板 | 关联 `MapBasic` |
| `grid_id` | int/string | 王座所在方格 | 地图正中心 |
| `pos` | string | 王座展示坐标 | 与地图工具一致 |
| `fog_layer` | int | 所属迷雾层级 | 层级 3 |
| `attackable_day` | int | 可攻击开服天数 | 建议 D21 |
| `throne_rule_ref` | int/string | 既有王座战规则引用 | 不重写王座战核心配置 |

# 迷雾配置

## `FogLayer`

| 字段 | 类型 | 说明 | 填表要点 |
|------|------|------|----------|
| `fog_layer` | int | 迷雾层级 | 0（出生区）/1（中间圈）/2（核心圈）/3（王座） |
| `layer_name` | string | 层级名称 | 后台识别 |
| `unlock_day` | int | 开服第几天开放 | 层级 1 建议 D8，层级 2 建议 D15，层级 3 建议 D21 |
| `unlock_time` | string | 当日具体时间 | 按服务器时区 |
| `show_object_model` | bool | 未开放前是否显示对象美术形象 | 默认是 |
| `hide_object_data` | bool | 未开放前是否隐藏铭牌、LOD、归属、类型和战斗状态 | 默认是 |
| `block_object_click` | bool | 未开放前是否屏蔽对象点击与详情交互 | 默认是 |
| `block_march` | bool | 未开放前是否阻挡行军 | 默认是 |

# 出生分配配置

## `SpawnRegion`

| 字段 | 类型 | 说明 | 填表要点 |
|------|------|------|----------|
| `spawn_region_id` | int/string | 出生区 ID | 4 个扇形区 |
| `region_id` | int/string | 关联地图分区 | 必须为出生区 |
| `auto_assign_rule` | enum | 自动分配规则 | 人数最少、密度最低等 |
| `capacity_limit` | int | 容量上限 | 达上限后不自动分配 |
| `density_threshold` | int/float | 密度阈值 | 结合落城尺寸和阻挡区，判定"接近上限" |
| `default_spawn_points` | string/list | 默认落城点集合 | 地图工具输出 |

# 占领规则配置

## `FortressOccupyRule`

| 字段 | 类型 | 说明 | 填表要点 |
|------|------|------|----------|
| `rule_id` | int/string | 占领规则 ID | 可按地图或区域拆分 |
| `fortress_type` | enum | 适用堡垒类型 | 普通、王座关联等 |
| `base_occupy_time` | int | 基础占领时间 | 秒或分钟，复用现有 kvk 堡垒规则 |
| `shield_time` | int | 占领成功后的免战时间 | 建议 12-24 小时 |
| `kvk_occupy_time_multiplier` | float | KVK 期间原服堡垒/龙巢占领时间倍率 | 建议 2-3 |
| `alliance_fortress_limit_group` | int/string | 堡垒上限组 | 关联联盟科技 |
> 联盟解散后，堡垒、圣坛和龙巢按主案立即转为中立，不配置延迟字段。不配置"重建联盟"识别与限制。任何新创建的联盟均视为新联盟，占领堡垒数为 0 时按主案首战规则处理。免战触发时的部队遣返逻辑参考王座结算规则，复用现有实现，不在本表新增开关。

# 联盟科技配置

## `AllianceTechBranch`

| 字段 | 类型 | 说明 | 填表要点 |
|------|------|------|----------|
| `tech_id` | int/string | 科技 ID | 新增或复用 |
| `tech_name` | string | 科技名称 | 展示文案走多语言 |
| `branch_type` | enum | 分支类型 | 堡垒上限 / 龙巢上限 |
| `level` | int | 科技等级 | 按项目科技体系 |
| `value` | int | 当前等级提供的上限 | 堡垒建议结合 30-60 满级目标 |
| `cost_group_id` | int/string | 升级消耗组 | 复用联盟科技消耗体系 |
| `unlock_condition` | string | 解锁条件 | 如联盟等级或前置科技 |
| `enabled_server_type` | enum | 启用服务器类型 | 仅新服模板启用 |

# 填表自检

- [ ] 新服地图模板与旧服地图模板已明确隔离。
- [ ] 每个出生区至少配置可用的初始堡垒。
- [ ] 堡垒和龙巢等级已按圈层配置并通过梯度校验。
- [ ] 初始堡垒不可被占领，但能提供首战可攻击目标。
- [ ] 每个普通堡垒都只配置上、下、左、右四邻关系，互邻关系已校验，未出现对角或非四邻攻击关系。
- [ ] 龙巢的相邻堡垒列表与地图交叉点一致。
- [ ] 圣坛只配置在可占领堡垒内。
- [ ] 迷雾层级开放时间不早于对应玩法目标需要的开放时间。
- [ ] 迷雾未开放时对象模型可见，铭牌/LOD/归属等数据层隐藏且点击被屏蔽。
- [ ] 王座可攻击时间不早于核心圈开放时间。
- [ ] KVK 期间堡垒与龙巢占领时间倍率已配置。
- [ ] 旧方尖碑、中心堡垒、远征堡垒相关计数已在对应任务、成就、活动与排行配置中直接替换或禁用。
- [ ] 最低客户端版本已确认。
